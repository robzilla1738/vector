## Cross-section acceptance

- **Closed scoped route gates:** [Appearance full-document reload](../release/test-artifacts/native-s9-settings-document-reload-2026-09-28-a/manifest.json) and [General/Appearance Back/Forward](../release/test-artifacts/native-s9-settings-history-2026-09-28-a/manifest.json). The Models batch does not alter routing, so duplicate route journeys are unnecessary.
- `collectSettingsFields` reads actual primitive metadata, but `settings-search.ts` still merges a hand-maintained fallback. Its removal must follow real field coverage, not a count of rail rows. New Models fields already use `SettingsField` and participate in this generated portion.
- `components/Settings.tsx` still owns assembly, Connections tabs, routes and indexing. Delete it and `settings-search.ts` only after every required destination migrates. Extensions and the legacy Vault route are extra supported surfaces, not replacements for Selection & Capture.
- Hidden Experimental must derive from S1 feature stages and remain outside the normal rail. No implementation was found in the current Settings source.
- ACCESS owns the required owner review of four sections in both themes plus VoiceOver/reduced-motion/contrast. Full S9 is complete only when each required section has working service behavior, honest capability/policy/Private state, generated field coverage, durable preferences, focused native evidence and the legacy deletion; S14 then consumes that evidence without repeating unrelated journeys.
