# Frame-bound selection and translation utilities

Original implementation of `docs/spec/ui/utilities.md` Selection/lasso, Translation status and isolated-frame constraints, with `visual-measurements.md` M3/M5/M6. Screenshot capture is a separate root-owned slice.

The isolated content module captures selected text in its actual document. A browser-issued runtime port binds the extension sender, tab, frame, committed document and regular/private mode. The background verifies the exact document again before requests and during streaming. It resolves the current native profile/account rather than accepting account or tab identities from a page. Malformed/foreign/inactive senders fail closed. Navigation, changed source text, disconnected nodes, foreign documents and moved editable targets invalidate replacement.

The 32px handle and Alt+Shift+L open a 336px lasso card with original selection, instruction, real streamed preview, cancel, completed-only copy/apply and temporary task review. Textarea/input replacement changes only the captured slice after full-value comparison and beforeinput approval. Sensitive/password fields are excluded. Editable rich content is supported only for one text node; other selections retain a copy fallback. Output is always plain text, never HTML. A refused editor or clipboard failure is shown without claiming success. Cancellation preserves the original and cannot promote partial output to an applicable result.

Alt+Shift+T opens the translation pill. Source detection remains separate from the target language. Safe page text nodes receive stable segment IDs; forms, inputs, editable content, code, script/style, explicit no-translate and the utility host are excluded. Results must contain every expected ID exactly once. All source/document checks complete before synchronous text-only application. Originals are retained for restore. A page change prevents application; restore changes only nodes whose current text is still exactly the utility's applied value and reports skipped page-owned changes. Cancelling/restoring never applies partial JSON. Limits are 400 segments, 64k source text and 128k completed output; oversized pages receive an explicit smaller-selection error.

## Real engine integration

The runner calls the existing sessions.create/prompt/eventsSince/get/messageRows/abort/delete procedures. Request/session/document IDs and monotonic cursors reject obsolete chunks. Completion comes from the idle session's actual assistant transcript. Prompts distinguish user instruction from untrusted selected/page data; document URL credentials/query/hash are not sent to the model. No canned transform or translation implementation exists in production.

Sessions use trigger page-utility, read-only policy with tool denial, ephemeral/private mode, exact native profile/mode binding and disabled memory extraction. Root separately owns the central empty-tool/no-ambient-instructions guard and volatile utility-session storage. These are required integration dependencies. Cancel aborts while retaining temporary review; superseding, dismissing and frame disconnect dispose through sessions.delete. Creation races are checked again after the session exists. Open task is intentionally temporary while its utility remains open.

Root applies `docs/implementation/page-utility-hooks.patch` to the content/background entries and adds all_frames:true for the existing HTTP(S) content script. Opaque/about frames remain unsupported. Root also owns the separate classic-script IIFE build correction for content.js; no shared main/background/content/Vite/features/router file was edited by this lane. No new daemon schema is required.
