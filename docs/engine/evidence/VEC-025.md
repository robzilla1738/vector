# VEC-025 Optional independent JavaScript VM research

**Acceptance:** feature manifest, Test262 subset, embedding tests. Do not replace V8 without evidence.

**Evidence:** `engine/crates/ve-vm` expression interpreter (arithmetic, unary, equality, relational, logical, ternary, typeof, string concat, object literals, property access, env identifiers). Dedicated workers evaluate `postMessage` expressions in this VM. `engine/conformance/test262-subset/*.js`. V8 remains production (`EngineConfig.scripting` + `ve-script`).

**Tests:** `cargo test -p ve-vm`.
