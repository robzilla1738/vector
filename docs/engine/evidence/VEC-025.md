# VEC-025 Optional independent JavaScript VM research

**Acceptance:** feature manifest, Test262 subset, embedding tests. Do not replace V8 without evidence.

**Evidence:** `engine/crates/ve-vm` expression interpreter (arithmetic, unary, equality, relational, logical, ternary, typeof, string concat, object/array literals, index access, modulo, bitwise `& | ^`, void, `if`/`else`/`while`/`for`, `var`, assignment). Dedicated workers evaluate `postMessage` expressions in this VM. `engine/conformance/test262-subset/*.js` (22 files). V8 remains production (`EngineConfig.scripting` + `ve-script`).

**Tests:** `cargo test -p ve-vm`.
