# VEC-010 Navigation, frames and storage

**Acceptance:** multi-origin, iframe, history, storage isolation, IndexedDB/worker lifecycles where demanded.

**Evidence:** existing frames/history/cookies. IndexedDB origin-partitioned put/get/delete, unique indexes, compound key paths, cursors, versionchange only on version bump. Dedicated `Worker` scripts with `onmessage`/`postMessage` evaluate in a page-isolate function realm (`var document = undefined`) so `typeof document === "undefined"` and `typeof WeakRef === "function"` without a second V8 isolate. Unresolved worker URLs still echo `postMessage`. A second V8 isolate cannot be created from a page host callback (`HandleScope` SIGSEGV). URL worker scripts are fetched. SW intercepts `respond:` bodies and `event.respondWith(new Response("…"))`; fetch listeners without `respondWith` leave the network response. `document.implementation.createHTMLDocument` is a second document node with its own doctype/`html`/`head`/`body`/`title`, not the browsing document. Same-origin `iframe` without `src` gets an `about:blank` HTML document on insertion; `Node.isConnected` walks to any document ancestor.

**Remaining:** second V8 isolate per worker (cannot enter from a page `HandleScope`); complete SW fetch event.respondWith for arbitrary Response construction.

**Tests:** `engine/crates/ve-agent/tests/bindings.rs` `indexeddb_and_worker_round_trip`, `indexeddb_index_cursor_and_isolated_worker`, `iframe_about_blank_isconnected`, `indexeddb_unique_compound_and_versionchange`, `create_html_document_and_live_collections`, `doctype_pi_and_prefixed_html_nodename`, `frames.rs`.
