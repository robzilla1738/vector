**Acceptance:** multi-origin, iframe, history, storage isolation, IndexedDB/worker lifecycles where demanded.

**Evidence:** existing frames/history/cookies. IndexedDB origin-partitioned put/get/delete, unique indexes, compound key paths, cursors, versionchange only on version bump.
