# VEC-010 Navigation, frames and storage

**Acceptance:** multi-origin, iframe, history, storage isolation, IndexedDB/worker lifecycles where demanded.

**Evidence:** existing frames/history/cookies. IndexedDB origin-partitioned put/get/delete, unique indexes, compound key paths, cursors, versionchange only on version bump, `IDBTransaction.abort` restores the store snapshot. Dedicated `Worker` `postMessage` runs in a **second V8 isolate on a worker thread** (`eval_worker_isolate`); `typeof document === "undefined"` and `typeof WeakRef === "function"`. Fallback is `ve-vm` when isolate eval fails. URL worker scripts are fetched. `importScripts` concatenates fetched files into the worker source before isolate eval. SW `importScripts` fetches and inlines (and evals from a URL map in the persistent isolate). `clients.claim()` during activate sets `navigator.serviceWorker.controller`. A second `register()` of a changed script sits in `waiting` until `self.skipWaiting()` promotes it. `clients.matchAll()` returns window clients this worker controls; `{includeUncontrolled:true}` includes same-origin clients and dedicated `Worker` clients (`type: "worker"`). Window `Client.postMessage` from a fetch handler delivers a `message` event on `navigator.serviceWorker`. `SharedWorker` exposes a `port` that round-trips `postMessage`. SW intercepts `respond:` bodies and `event.respondWith(new Response("…"))`; `register` fires `install` then `activate` (including `skipWaiting` / `waitUntil`); `navigator.serviceWorker.ready` resolves to the last registration. Same-origin `iframe` without `src` gets an `about:blank` HTML document on insertion.
