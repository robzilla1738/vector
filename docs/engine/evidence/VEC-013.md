# VEC-013 Complete paint and direct presentation

**Acceptance:** text/image items not dropped; GPU text uses glyph outlines when fonts are loaded; present without CPU readback on GPU path; damage tracking.

**Evidence:** `build_scene_fonts` fills `FontSystem` glyph outlines as vello paths (bitmap fallback if an outline is empty). `from_layout_with` emits overflow clips, opacity groups, and `<img>` pixels. Images use `ImageCache`. `present_scene` has no readback. `SoftwareRenderer::present_into` retained CPU buffer. `Compositor` damage bits.

**Tests:** `text_and_image_items_are_not_dropped`, `glyph_outlines_encode_when_fonts_are_loaded`, `from_layout_emits_opacity_and_overflow_clips`, compositor damage assertions.
