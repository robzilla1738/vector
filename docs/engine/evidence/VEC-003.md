# VEC-003 Authoritative network and storage broker

**Acceptance:** forged identities, DNS rebinding, private-network, agent egress, credential stripping.

**Evidence:** `ve-net/src/broker.rs` stamps parent context (forged child id rejected). `policy.rs` revalidates resolved IPs, strips userinfo, default-blocks loopback/private, agent allowlist. HTTP/3: `parse_h3_alt_svc` plus `http3::get` / `get_with_roots` over QUIC (`quinn` + `h3`); loopback GET returns a body. After `Alt-Svc`, later fetches to that origin try HTTP/3 (`ProtocolSupport.http3_spoken`).

**Tests:** `cargo test -p ve-net --lib broker`, `policy` tests including `dns_rebinding_resolved_addresses`, `http3::tests::alt_svc_h3_is_detected`, `http3::tests::loopback_get_speaks_http3` (`--features http`).
