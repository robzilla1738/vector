# VEC-008 Web IDL bindings and JS/DOM object lifetime

**Acceptance:** author-created events cannot forge trusted state; prototypes; stale refs after slot reuse.

**Evidence:** harness `event.isTrusted-not-forgeable`. `bindings.rs` stale ref after recycle fails. DOM prelude wrappers. Pinned IDL in `engine/crates/ve-script/idl/` includes Node/Element/Document/HTMLElement/Window, observers, forms, Worker/ServiceWorker/XHR, `MediaQueryList`, `ARIAMixin`, `Clients`/`Client`, `ServiceWorkerGlobalScope`. Generated traits from `build.rs`. Live document named properties (`embed`/`form`/`iframe`/`img`/`object` by `name`/`id`). Layout-aware `innerText` (display:none / `br` / blocks; detached falls back to `textContent`); `outerText` replaces the node. ARIAMixin string reflection (`role` / `aria*`) and in-scope `ariaLabelledByElements`. Live `NodeList` for `getElementsByName`. Cached `document.embeds` / `document.plugins` identity. `DOMStringMap` dataset. `translate`/`dir` on `HTMLElement`.

**Remaining:** full upstream `idlharness.js` over complete spec IDL; wrapper identity across realms. Official innerText/outerText, ARIA element-reflection, `historical.html`, and `document.cookie` families PASS. WebGL/WebGPU are explicit compatibility tracks (`getContext("webgl") === null`, `capabilities.webgl/webgpu: false`). Do not read this as the whole `html/dom` family finished.

**Tests:** `bindings.rs` `document_named_properties_are_live`, `inner_text_skips_hidden_and_outer_text_replaces_node`, `aria_string_and_element_reflection`, `generated_idl_includes_aria_clients_and_skip_waiting`, `canvas_webgl_and_webgpu_are_null`, wpt-harness `wpt-nameditem.html`, `wpt-innertext.html`, `wpt-outertext.html`, `wpt-aria-reflection.html`, `wpt-aria-labelledby.html`.
