# VEC-008 Web IDL bindings and JS/DOM object lifetime

**Acceptance:** author-created events cannot forge trusted state; prototypes; stale refs after slot reuse.

**Evidence:** harness `event.isTrusted-not-forgeable`. `bindings.rs` stale ref after recycle fails. DOM prelude wrappers. Pinned IDL in `engine/crates/ve-script/idl/` now includes `HTMLCollection`, `DOMImplementation`, `Document.links`/`scripts`/`forms`/`images`, writable `body`. `document.implementation.createHTMLDocument` allocates a detached document node (with `<!DOCTYPE html>`) in the same arena. `createDocument` / `createDocumentType` / `createProcessingInstruction` exist. HTML `createElementNS` stores the prefix so `x:b` has `nodeName` `X:B`. Generated traits from `build.rs`. `HTMLCanvasElement.getContext("2d")` is a `CanvasRenderingContext2D` that records `fillRect`/`clearRect` into a per-node software buffer.

**Remaining:** full upstream `idlharness.js` over complete spec IDL; wrapper identity across realms; Path2D, ImageData, WebGL.

**Tests:** `engine/crates/ve-agent/tests/bindings.rs` `create_html_document_and_live_collections`, `doctype_pi_and_prefixed_html_nodename`, `canvas_fillrect_records_ops`, wpt-harness `idl-element.html`, `wpt-document-body.html`, `wpt-createhtmldocument.html`.
