# VEC-014 Native browser shell and platform integration

**Acceptance:** native-only view; chrome cannot be spoofed; no Chromium required; OS input shares the live document.

**Evidence:** `ve-api::NativeBrowser` tabs, chrome title vs page title, chrome AX (`fromPage: false`), screen-reader chrome summary, clipboard copy/paste events, permissions, downloads, shared observe. `handle_event` is the OS/human path (keys, IME, pointer, navigate, copy, paste). `present()` paints the live page into a retained framebuffer. `ve-shell` CLI; `ve-shell --gui` uses winit + softbuffer when built with `--features window`. CI clippy for `--features window` on macOS. `update_status()` reports signed updates as unimplemented.

**Tests:** `engine/crates/ve-api/src/shell.rs`.
