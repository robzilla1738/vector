# VEC-014 Native browser shell and platform integration

**Acceptance:** native-only view; chrome cannot be spoofed; no Chromium required; OS input shares the live document. Electron is not the product.

**Evidence:** `ve-api::NativeBrowser` identity `product: ve-shell`, `chromium: false`, `electron: false`. Packaged `release/ve-shell` (`pnpm package:local` / `--features product`) prints `backend: vector-engine`, `chromium: false`. `pnpm dev` launches `ve-shell --gui`; Electron hybrid is `pnpm dev:electron` / `pnpm package:electron`. `handle_event` is the OS/human path. `present()` paints the live page. CI clippy for `--features product` on macOS. `tests/smoke/packaged.mjs` accepts native-only `release/ve-shell`.

**Tests:** `engine/crates/ve-api/src/shell.rs` `page_cannot_spoof_chrome_title`.
