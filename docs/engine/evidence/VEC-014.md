# VEC-014 Native browser shell and platform integration

**Acceptance:** native-only view; chrome cannot be spoofed; no Chromium required; OS input shares the live document. Electron is not the product.

**Evidence:** `ve-api::NativeBrowser` identity `product: ve-shell`, `chromium: false`, `electron: false`, `accessKit: true`. Packaged `release/ve-shell` + `ve-host` (`pnpm package`). `VECTOR_NATIVE_ONLY=1` does not create an Electron `WebContentsView` paint shell for engine tabs. `handle_event` is the OS/human path. `present()` paints the live page. Chrome AX cannot be spoofed. CI clippy for `--features product` on macOS.

**Tests:** `engine/crates/ve-api/src/shell.rs` `page_cannot_spoof_chrome_title`, `engine/crates/ve-api/src/updates.rs` `valid_signature_verifies_and_tamper_fails`, `ve-a11y` `os::tests::shell_tree_includes_chrome_and_page`, `tree::tests::live_regions_and_slot_assignment`.
