# Vector Engine evidence (VEC-001–025)

Each package lists the acceptance target, current-tree evidence, and remaining
gaps. Identity is the native Vector Engine (`vector-engine`), not Chromium.

**The roadmap is not complete.** Rows marked subset/baseline/research are
not full acceptance. Held-out Speedometer/JetStream/MotionMark, full upstream
WPT, Electron-free desktop, second V8 worker isolates, and M3 2× p95 are
still open.
