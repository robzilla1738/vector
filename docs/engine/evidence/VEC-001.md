# VEC-001 Strict engine identity and packaging

**Acceptance:** missing addon/host/wrong protocol/sandbox failure cannot start Chromium or run untrusted content in-process. Hybrid stays labeled. Benchmarks fail if identity differs.

**Evidence:** `always` + missing engine sets `backendUnavailable: true` and `pages.open` throws `backend_unavailable` immediately (no Chromium substitute). `VECTOR_NATIVE_ONLY=1` refuses Chromium even when chrome is requested. Hybrid `auto` stays labeled. `Hub::identity` publishes abi/protocol/isolation/sandbox/securityProfile. `pnpm package` builds `ve-shell` + `ve-host`. `tests/benchmarks/run.mjs --require-identity`.

**Tests:** `tests/unit/router.test.ts`, `engine/crates/ve-napi` identity, `tests/unit/vector-engine-driver.test.ts`.
