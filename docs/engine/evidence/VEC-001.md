# VEC-001 Strict engine identity and packaging

**Acceptance:** missing addon/host/wrong protocol/sandbox failure cannot start Chromium or run untrusted content in-process. Hybrid stays labeled. Benchmarks fail if identity differs.

**Evidence:** `apps/runtime/src/services/router.ts` `always` returns `vector-engine` with `fallbackAllowed: false`. `ve-napi` `ABI_VERSION` + `HOST_PROTOCOL` handshake. `Hub::identity` publishes abi/protocol/isolation/sandbox/securityProfile. `tests/benchmarks/run.mjs --require-identity`. `tests/unit/router.test.ts`.

**Tests:** `tests/unit/router.test.ts`, `engine/crates/ve-napi` identity, `tests/unit/vector-engine-driver.test.ts`.
