# VEC-016 Action contracts, receipts and uncertain effects

**Acceptance:** receipts describe observed state; no claimed remote success; takeover does not rewrite dispatched work as canceled.

**Evidence:** Executor stamps `receipt.uncertain` on click/fill/type/select/check/press without `expect`. `remoteConfirmed` only when expect conditions ran. Takeover sets `dispatchedBeforeTakeover`. Desktop `StepTimeline` shows Uncertain / Confirmed / Takeover-interrupted (`data-testid=tl-receipt`).

**Tests:** `tests/unit/roadmap-agent.test.ts`, `apps/desktop/renderer/src/components/StepTimeline.test.tsx`.
