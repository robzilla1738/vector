# VEC-023 Concurrent browsing and memory governance

**Acceptance:** a busy page must not block siblings; no cross-profile leak; process RSS is measured.

**Evidence:** Independent `EventLoop`s. `VectorEngine` multi-page test. Context cookie isolation already in ve-api. `ve_core::process_rss_bytes` (Linux VmRSS / macOS `ps`). Optional `host_package_energy_uj` from intel-rapl. NativeBrowser identity includes `rssBytes`.

**Tests:** `concurrent_pages_do_not_share_scroll_or_block_each_other`, `contexts_isolate_cookies_and_close_their_pages`, `independent_loops_do_not_block_each_other`, `ve-core` `rss_is_reported_on_unix_hosts`.
