# VEC-015 Versioned semantic query service

**Acceptance:** page/frame/document/generation identity; incremental queries match full recompute; token budgets.

**Evidence:** `EngineObservation.query_version`. `document_epoch` + revision. `changesSince` vs full snapshot. Observation budgets in `ve-a11y`. `Scope::Forms` returns a strictly narrower element set than `Scope::Full` on mixed pages.

**Tests:** ve-api observe/execute round trip, a11y observation tests, `engine/crates/ve-agent/tests/held_out.rs`.
