# VEC-024 Hermetic replay and safe speculation

**Acceptance:** missing archive is nondeterminism; speculative writes denied; GET not assumed harmless; live revalidation required.

**Evidence:** `ReplaySession::revalidate_live` compares archive status to a live check; missing live I/O is nondeterminism; status mismatch refuses archive-only execution. Speculative GET is denied unless `safe_for_speculation`. Broker denies prefetch.

**Tests:** `ve-replay` unit tests; `ve-net` `replay::tests`, `broker::tests::speculative_prefetch_is_denied`; `ve-api` `hermetic_mode_blocks_unarchived_http`, `hermetic_replay_serves_archived_get`.
