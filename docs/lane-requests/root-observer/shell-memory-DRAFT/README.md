# Shell memory producer draft

Native-owned zero-argument sampler reads the current shell renderer from the existing genuine native owner. It retains the original WeakDocument and scope, checks before/after kernel read, refuses exited/unavailable processes, and publishes exact kernel UUID/start/physical-footprint and monotonic sampling interval. No PID selector, JS heap estimate, subtractive accounting or RSS inference. The independent collector requires genuine direct-child fixed-operation receipts, increasing sequence, unchanged native process/owner, exact paired product identity and AC power for every trial.

This is an unadopted draft until shared native fixture/GN/transport and actual journey caller are integrated. The current builder candidate remains untouched. Source-only protocol checks and local SDK kernel API syntax checks do not establish whole-native compilation, real memory measurements or qualification.
