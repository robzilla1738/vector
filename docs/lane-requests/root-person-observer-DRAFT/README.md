# Closed native person observer draft

Nine new source leaves only. This is not a canonical native packet or a ready
build. It requires the frozen f0fd native person-read receipt and reserved
AUX_OBSERVER world. Runtime/contracts/host/build wiring and genuine native
navigation, replacement, connection retirement and teardown controls remain
required, as do compilation, journeys and performance qualification.

The associated endpoint has only Prepare and Read. Prepare acknowledges a
renderer receiver bound to its original DocumentToken; the browser rechecks its
retained WeakDocument/person receipt before dispatching Read. Read consumes the
prepared native UUID, rechecks the original renderer document before and after
the one fixed script, and clears receivers on document replacement/detachment.
No caller chooses a script, method, world or frame. The native controller admits
one pending read per tab, bounds request/result bytes and lifetime, refuses
navigation/authority retirement, and clears state before delivering callbacks.
The pending host adapter must also retire original connections and enforce a
bounded Profile-wide count; a passed generation alone is not that adapter.

Returned document identity is an original browser DocumentUserData UUID scoped
to the admitted document. It is not a synthetic driver attachment or a runtime
phase label. The ordinary route will use that identity without raw CDP.

The fixed reader completes bounded metadata admission across the document and
open shadow roots before reading text. Any protected field or editable region
refuses the entire read, including possible echoed text. It never reads form
value/defaultValue, invokes checkValidity, dispatches events or clicks. Ordinary
forms return labels/types/refs; values are deliberately absent. It returns real
bounded headings, tables, dialogs and visible text, and strictly limits extract
attributes. This tighter ordinary read is separate from agent actuation.

Driver compilation, fixed-header regeneration/check, scoped lint and nine
synthetic tripwire/bounds controls pass. The exact new-leaf request applies and
reverses byte for byte. Builder's independent read-only upstream API review
found no unsupported API; generated Mojo signatures and native behavior remain
uncompiled/unexecuted. Source controls do not qualify browser behavior.
