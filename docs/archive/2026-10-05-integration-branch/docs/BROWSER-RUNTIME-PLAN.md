# Aux: browser-as-agent-runtime build plan

## Context

Aux is a Chromium 154 fork. It has 135 patches in `chromium/patches/series`. The UI is a React 19 + zustand WebUI shell (`apps/shell`) served at `chrome://aux/` inside Chromium's Webium `WebUIBrowserWindow`. Each tab is a real `WebContents`, shown in the shell through SurfaceEmbed. A Node runtime (`apps/runtime`) runs once per loaded Chromium Profile, reached over an authenticated Unix socket. Native services live in `~/aux-chromium-stable/chromium/src/chrome/browser/ui/aux/**` (`methods/*.cc`, `AuxMethodRegistry`).

The owner wants Aux to be a browser that *has* an agent and IDE-grade tools, at reference-product polish. The 17-feature wishlist plus three differentiators has to land with unattended qualification journeys and be flipped to `on` in the feature registry. Today, much of that wishlist is only declared or partially built.

### F11: Smart download rename with Undo (`smartDownloadNames`, L9)

**Settings › Downloads**
- "Rename downloads": Off / **Only unclear names** (default) / All.
- "Use AI": on by default, via the Gateway `fast` route. It sends the file name, source host, page title, MIME type and first-page text (≤2 KB). It never sends the URL path or query, or the file contents beyond that.
- Exclusions: host globs, extensions, MIME types.
- Template, default `{date} {site} {title}`.

**Flow**
1. **Native eligibility.** `DownloadSignals::Publish` on the first `COMPLETE` (`shell_events.cc:516`). Skip when any of these hold:
   - `TARGET_DISPOSITION_PROMPT`;
   - a forced path;
   - a SavePackage;
   - dangerous or insecure;
   - opened or open-when-complete;
   - a private Profile.

   Otherwise call `downloads.completedNative` with `{id, filename, mime, sourceHost, tabTitle, referrerHost, endedAt}`.
2. **Runtime `services/download-naming.ts`.**
   - The "unclear" classifier regex is `^(download|file|document|untitled|image|scan|export)[\s_-]*\(?\d*\)?$`, plus UUIDs, hex strings of 16+ characters, `IMG_\d+`, and digit-only names.
   - Apply exclusions.
   - AI path: `native.downloadPreviewText` (PDFKit page 0, or the first 2 KB of `text/*`), then `model.generateStructured` → `{stem≤100}`. Same pattern as `agent/tab-name.ts`.
   - On error or a 4 s timeout, use the template.
   - Sanitize: no `/ : \0`, no control characters, no leading dot.
3. **`native.renameDownload{downloadId,expectedName,stem,mode}`.**
   - Always keeps the original extension.
   - Rechecks eligibility and that the download completed less than 30 s ago.
   - Checks inode and size, and that the file isn't open (`proc_listpidspath`).
   - Tries `stem (2..20)` with its own `renamex_np(RENAME_EXCL)`, which fixes the race in `download_utils.cc:782`, then calls `DownloadItem::Rename`. Renaming in the same directory preserves quarantine and `WhereFroms`.
   - Paths are resolved by GUID only.
4. **Durable receipt.** Table `download_renames`, following the 0100/0103 conditional-undo pattern and `BrowserDownloadLedger.undo`. The runtime emits `download.renamed`.
5. **Toast:** "Renamed to *…* — Undo". Undo is also available from the download row for 24 h. `downloads.undoRename` reports a conflict if the original name is now taken.
