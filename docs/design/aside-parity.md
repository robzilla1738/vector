## Meaning of the result column

- **Compared**: concrete reference implementation/geometry and Aux implementation were read; any remaining difference is named. Still needs a matching native observation.
- **Partial**: Aux has the capability, but the visible composition, option set or state coverage differs or was only partly compared.
- **Open**: absent in the bounded source search, or reference/runtime evidence is insufficient to decide what to implement.
- **Aux decision**: an existing owner decision intentionally differs. Keep the capability and apply shared visual primitives; do not copy Aside's branding, paid service, permissions or account model.
- **Indexed**: the entry points were located, but a complete state/option comparison has not been performed. This is explicitly unfinished work.
