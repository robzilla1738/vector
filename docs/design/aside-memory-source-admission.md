## Confirmed boundary

Independent review K2 is a real admission gap, qualified by its exact reproduction: actual legacy typed page result → real pipeline extractRun/accept → disposable SQL expires_at=0; ContentMemory.recallDocuments returns [], but pipeline lexical episodic recall returns the article quote. This proves persisted-expiry behavior before explicit Forget/prune, not natural-clock/native observations. Evidence is the frozen reviewer case and log, hashes in the adjacent evidence JSON. The gate must not use historical article evidence to grant a fresh article read, recapture, or admission marker.

Current MemoryPipeline.sourceEligible (296–370) refuses private/excluded/unverifiable page sources and explicit Memory-fed config, but knows neither original memory_search/read ledger entries nor legacy typed history. eligibleForRecall (416–438) trusts a completed same-Space report containing the claim; the old quoted report therefore revalidates itself. Checking current ContentMemory pages cannot fix this: old claims have no canonical captured article refs and rereading an article would create a new implicit grant.

## Smallest recommended rule

Treat an automatic run-report Memory source as *not independent* when its original execution or authenticated copied/effect family received Memory content, or when legacy/unproven Memory use cannot establish what was received. Refuse extraction/model recall from that report rather than reconstructing missing article admission. Genuine modern nonempty owner/history/episodic results remain derived under the existing Memory-of-Memory policy. However, a genuine modern call that canonically completed with matches=[] or an exact canonical no-content error need not block otherwise independent research: no Memory content was fed by that call. This exception must be proven from the original typed call, execution ledger and exact paired completed result under the genuine modern admission version, plus the original ownership/final-publication fences. A modern marker alone, a result-looking human message, or a caller-supplied empty result is not proof. Pending, interrupted, truncated, malformed, conflicting, unpaired, or otherwise unknown results are unavailable. The exception grants no article/source access and never backfills a legacy marker. sourceEligible still applies every existing selected-context, injected-summary, page, privacy, policy and sensitivity exclusion; this is not a new transcript-erasure policy.

For the exact K2 legacy case, refusal applies regardless of whether the original article is currently present, expired, removed, or recaptured. A modern admission marker is not a bypass for this independence test. An unrelated ordinary run with no Memory call remains eligible under all existing checks. Actual independent owner documents, owner-pasted notes and owner items keep their existing explicit paths. An ownerEdit attached to a blocked generated claim stays exactly inspectable but does not silently become an independent owner source; existing explicit owner document/paste reaffirmation remains available.

## One candidate-scoped proof, no global scan

Extract the existing bounded original Memory-call detection used by frozen services/legacy-memory-retirement.ts assertLegacyMemoryContext (516–592) into a shared *refusal-only* helper. Keep global inspectLegacyArticleHistory (139+) exclusively with explicit Forget/copy owners. Do not invoke storedRunIds or the 4096-run global retirement scan from recall, Dream, extraction, browser startup, or each model turn.

The helper starts only from candidate sourceRunIds already present in this operation's bounded claims, inbox, generated-document sourceRefs, completed-session page, or explicit extract/discovery input. Use protectedRunFamily/runAncestry with existing canonical Set receipts and subagent record checks; raw setId, branchSourceRunIds, or model-provided IDs cannot manufacture family authority. Check original branch/prefix identity through the existing codec/receipt mechanism before accepting a copied-source relationship. A plain parent report whose authenticated child made a Memory call must be refused, even if the parent contains no Memory token itself. A different parent execution sharing a Set ID stays independent.

First query original run_tool_calls for the actual names and candidate run ID. An actual legacy/unsealed Memory call is immediate refusal, with no transcript or article decryption required. For a genuine modern call, inspect its original canonical typed call/result pairing before classifying: any returned Memory content is derived; exact completed empty search or canonical no-content error can satisfy the no-content exception above. All actual Memory calls in the candidate family must be accounted for; one empty call cannot clear another nonempty or unknown call. Recheck the exact call/input/result/ledger and family identities through final publication. If the ledger is absent, use the existing canonical codec-backed message/park reader to detect typed assistant tool-call, tool result, or parked result metadata for those exact names; absent original execution proof cannot qualify for the modern empty-result exception. Human prose/JSON mentioning memory_search is not proof of a call. An unpaired malformed historical result is never admission evidence; malformed, unreadable, incomplete, or over-budget relevant history is unavailable, never clean. Reuse the row decoder and canonical typed outcome classifier; do not relabel a global retirement inspector as model authorization or introduce a second transcript parser.

Construct an operation-local prepared eligibility/proof map, deduplicated by original run/family. Have sourceEligible/eligibleForRecall consume it rather than recursively decrypting the same history for every claim and every check. Prepare asynchronously in bounded pages with original operation signal/checkOwner/lease checks between pages; don't hide a synchronous all-history scan inside the existing synchronous filter. Keep fresh final validation of the immutable run/config/report, canonical family membership/receipts, original call metadata, and inspected encrypted transcript fingerprint. A missing proof is unavailable, not an optional callback success. The existing Repo.columnCipher and TranscriptStore(repo.db, repo.columnCipher) provide real decoding ownership; no new native grant, account, API, schema migration, or startup scan is needed.

Proposed admission work budget (new implementation constants, not measured existing behavior): share the existing depth32/family4096 hard authority ceilings, plus a deliberately lower per-operation history budget (e.g. 4096 rows/8 MiB aggregate, 1 MiB maximum row, 64-row pages). Stop immediately on proven legacy/unsealed Memory use or completed nonempty Memory content; a genuine modern call requires outcome classification before refusal. Reject the affected candidate family on limit/malformed ownership; do not truncate and certify a prefix. Operation-wide budget exhaustion returns explicit unavailable rather than producing a supposedly complete list. Preserve unrelated already-proven sources when a specific source is refused. No persistent boolean cache: per-operation reuse only, final proof revalidation, no invalidation timer. A future measured cache would need exact config/family/ledger/transcript identity; PRAGMA data_version alone is insufficient for same-connection writes.

## Scope left open

This closes fresh admission from unprovable historical Memory-derived reports; it is not physical retirement of stored claim bytes, a live Forget/fixed-point closure substitute, or a fix for CURRENT Space Memory retained across stage/apply. The separately accepted detached-generation/key-ownership restore design remains required. No new read or use grant is derived from historical inspection, and absence of an old ledger is not by itself proof of a clean transcript.
