# Retain the actual fresh-home journal directory

This source-only successor corrects a physical ownership gap in the inactive native-v2 initial-stage producer. Its previous journal store reopened the canonical home pathname. The real producer now duplicates the actual retained native home's directory handle, and the store duplicates that handle into its own ownership. A bad supplied descriptor never falls back to a pathname open. The store verifies its retained inode matches the canonical path before creating any journal directory or file, and keeps its existing before/after path/inode checks during operations. The temporary caller duplicate closes explicitly; the store closes its owned duplicate in deinit.

The store's path-only constructor remains available for nonauthoritative fixture/storage use. Neither constructor grants native policy, secure-row access, process admission or whole-writer custody. Actual production selection uses the retained-descriptor argument. No journal format, secret payload, selector, generation, Add/reconciliation or legacy format changes. The original source/receipts remain historical and unchanged.

`verify.py` checks count-one source edits, exact bytes, actual producer use and identity validation before mutation. The lean `check.sh` compiles only the store's required pure record dependencies and checks a retained duplicate after the caller closes its FD, wrong/invalid descriptor refusal without fallback, and a replaced-path inode mismatch before any file creation. It uses only newly created disposable directories and synthetic nonsecret records. No factory, Security query, credential, owner state, app, signing or OS grant executes.

The full production consumer graph must select these two logical successors instead of their predecessor copies; a later terminal-context consumer must also pass its actual retained-home duplicate when reopening this store. At preparation this proposal is inactive and its focused check is queued, not a claimed successful compile/runtime receipt. The accepted UI, native checkout and active host pins remain unchanged.
