# Hydrate a saved New Tab draft before the first Ask mount

The original editor initialization loads its saved draft only when startup mode is Ask. Search startup creates an empty editor even when its draft writer holds a saved text record. On the first Ask switch, session-composer's external-editor bridge `gu` registers that controller and immediately calls `handleRichInputChange(controller.getSnapshot())`. This publishes the empty Search snapshot and overwrites saved draft text. Attachment defaults are initialized separately and can remain present. Actual615 diagnostics confirmed a restored native page identity and a retained attachment; the earlier text entry used AX setValue and did not independently prove text was saved, so this proposal does not claim that observation alone established the overwrite.

Three count-checked anchors retain the supplied editor and mode transition: remember whether an untouched Search startup has a saved draft; before its first Ask subscriber notification, restore that record with the existing snapshot converter/controller and `emitUpdate:false`; cancel this pending restoration on any actual edit. Existing nonempty query text wins, and switching modes later never resurrects a cleared draft. No CSS, mode preference, layout, focus policy or new UI control is introduced.

Focused verification executes the actual transformed setMode function: Search startup stays unchanged, first untouched Ask restores before subscribers mount, a second toggle does not restore again, and edited/nonempty input wins. The complete transformed module parses. Exact full source/output hashes and anchor counts are recorded. Root only needs to restage the already reviewed newtab-editor leaf; no native rebuild or additional leaf allowance.

Actual acceptance: use genuine typeText to create a small draft, verify writer/storage textLength before Quit, restart in Search, toggle Ask, and verify restored text and the previously completed attachment. AX setValue alone is not evidence of a stored editor update. A delayed Ask panel mount should be allowed to settle before assessing missing attachment controls.
