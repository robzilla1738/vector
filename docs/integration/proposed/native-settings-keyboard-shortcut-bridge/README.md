# Supplied Settings keyboard shortcut bridge

Actual566 has no native implementation/schema for any of the four methods required by the supplied1852 capture hook. Its `h()` gate requires all four; therefore normal shortcut inputs are deliberately disabled. The mini popup has an additional real `getEnabled()` gate (its registered default is false). This proposal connects the existing supplied controls to actual command execution; it does not change HTML, JS or CSS or silently enable MiniPopup.

## Contract and provenance

The hash-pinned staged1852 `use-shortcut-capture-DGr8Ws5Z.js` is the authority for method names, arguments, eight command IDs, row fields, capture lifecycle and serialized key vocabulary. Its defaults are Command+S, Command+Shift+A, Command+E, Command+Shift+E, Command+Shift+C, Command+Shift+backslash and Command+Shift+minus. The global mini-popup fallback is Alt+Space, but a capable native owner is explicitly allowed to return its own actual registered default/current value; this proposal retains the existing real Command+Shift+Space default and any saved setting.

No original native C++ implementation for these four optional methods was recovered. This is an explicit Chromium155 bridge adaptation to the supplied UI contract. It must not be described as a recovered original preference schema or original Cocoa implementation. The normal browser defaults above come from the supplied hook; activating Command+S for Toggle Sidebar intentionally takes precedence over upstream Save Page. Each command retains its actual current155 enabled/model/profile guards.

## Implementation

- Four native extension functions expose snapshots, set/reset and capture suspension. The existing AuxFunction trust check remains mandatory. Command IDs and key grammar are closed to precisely the supplied list/vocabulary; duplicate effective accelerators and unrelated main-menu conflicts fail visibly. Overrides persist in one registered profile dictionary; incognito inherits the actual original profile's mapping.
- Real Cocoa pre-dispatch resolves these keys against the browser represented by the actual event window. It executes the genuine command through the existing native window host with normal enabled checks. No fake command result or replacement panel is introduced. Displaced static defaults are delivered to the focused responder instead of also firing the old browser command; other commands/extensions remain on the existing path.
- Capture is owned by actual calling WebContents userdata/observation. Real keys go directly to the focused responder during capture, bypassing browser/menu accelerators. The existing global listener is suspended while any capture exists; its preexisting suspended state is preserved. The supplied blur/visibility cleanup calls resume, and native page replacement, renderer exit and destruction also release the capture. This is not a permanent process-wide boolean detached from document lifetime.
- The mini-popup setter shares the actual PopupManager registration/persistence path. When enabled, a failed native registration returns an error and does not persist a successful-looking value. Global registration is temporarily resumed for that synchronous atomic change then restored to capture suspension. The actual enable preference, KeepAlive acquisition/release, profile ownership and managed-pref guards remain. Shared parser support includes the supplied backslash/minus forms, including startup preference re-registration.
- The seven browser IDs are the supplied IDs, including side-by-side34057 (`IDC_NEW_SPLIT_TAB`), not the independent34065 command. Native consumers are current `browser_command_controller.cc` real Toggle/TabSearch/Agent/NewTask/CopyURL/split implementations. No AI request or profile operation is used for verification.

## Lean verification and limits

`python3 verify.py` checks every baseline/output SHA, exact counted replacements, all new-file outputs and complete patch replay. `node contract.test.mjs` executes the actual pinned supplied hook in an isolated fixture: four-method capability gate, eight IDs, real setter/reset/conflict branches and backslash capture serialization; it also checks the native schema has each method exactly once. It does not exercise an app or claim native compilation/runtime acceptance.

Root should capture Ask Aux to an unused Command+Shift+J, blur, verify that it toggles the genuine panel on an external page while displaced Command+E no longer does, then Reset and verify Command+E. A duplicate should show the supplied conflict error. Capture should not launch the command being recorded; closing/navigating the capture page must restore normal handling. MiniPopup remains disabled when its actual enabled preference is false; enabling a system-wide feature is not simulated by enabling an input.

Remaining bounded limits: AppKit menu hint labels remain their existing static upstream accelerators; this patch changes actual keyboard dispatch and supplied Settings rows, not menu hint rendering. OS symbolic hotkeys may still conflict (as the existing Mac dispatcher documents), and no unverified claim of OS-global registration or keypress is made. Detached immersive child-window dispatch requires actual native observation; no active-window fallback guesses ownership if the window is not a registered browser. Native compile and real Settings behavior remain unverified until integration.
