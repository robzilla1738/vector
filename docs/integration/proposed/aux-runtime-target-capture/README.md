It is a storage/captured-crypto component, not an admitted host or complete addon. The accepted app, loader, UI and source pipeline are unchanged.

Selectors are generated only as `aux.<scope>.installation.v2` with `.meta/.sig/.kem/.dk` accounts. No key generation, scheme fallback, reset or hidden legacy unwrap exists.

Its read method performs protected calls and is **not executed in the fixture**. Missing, inaccessible, invalid and changed captures remain distinct and cannot become a fresh installation. The old interposer rejects this explicit group; this source must be used only by a separately reviewed clean host. The existing SDK authentication-UI deprecation warning is retained; no OS prompt or Security call occurs during checks.

Its constructor is private; no arbitrary core wrapper or successful-validator callback exists. Metadata retains the supplied absent-key_storage→enclave default. The source holds no globally selected scope and emits no private receipts. A content policy/captured context remains forgeable by a caller controlling its inputs; **it proves cryptographic/content consistency only**.
