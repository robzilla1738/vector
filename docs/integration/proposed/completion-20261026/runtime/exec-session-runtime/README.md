This source successor closes the known per-session HOME/TMP/cache/prefix producer and published-runtime read boundary. It does not modify the signed browser-only candidate, activate ES execution, or supply Apple authority.

The private selected scope creates only fixed `exec/{home,tmp,cache,prefix}` directories below its actual held Task session descriptor. Creation uses no-follow native descriptors, exact private mode/UID and empty ACL checks. Original global runtime home/tmp creation is removed. Explicit full-access HOME keeps its original meaning; other HOME and all TMP/cache/package prefix paths use the native session scratch. The original runtime seed remains shared, including its Python virtual environment: ordinary commands cannot mutate that shared environment. Existing native exclusive installer lease is the sole runtime mutation owner. Ordinary pip writes to the shared virtual environment therefore refuse; explicit per-project/per-session environment creation remains possible through the original command API.

A new, separate runtime boundary ABI is captured only from the reservation's existing RuntimeScope lease, never JS paths or a JS mode. All three actual original producers (ProcessWrap, SyncProcessRunner, contained linked PTY) copy it before constructing the native envelope. Every spawn revalidates its descriptor identity against the same retained native lease. Absent runtime grants nothing. A present shared runtime grants read/execute only; an actual exclusive native installer lease can write its contents while root/ancestor unlink stays denied. Other Task accounts, Control/browser state and app seeds keep their existing denials. The existing RuntimeScope remains retained until original process, transport and real ES cohort settlement.

Account invalidation is joined to the actual existing Bash drain signal and yielded ExecSession termination owner. The guard's original AbortSignal stays private; original close and native ES completion, rather than the cancellation Promise or signaling, release ownership. Original source-known termination behavior is preserved; signaling does not claim descendant closure. A missing original close or ES proof still retains unknown state.

`changes.json` contains exact predecessor/output hashes and count-one complete-file native replay anchors; `source.patch` supplies the readable diff. `entry.anchors.json` follows the existing selected exec resource anchors and separately patches the original selected guard return to expose its own AbortSignal. No new caller-selected authority is accepted. Full reconstructed original entry parsed successfully with Node; its hash is in `verification.json`. No native compilation, archive modification, linking, launch or fixture ran in this worker.
