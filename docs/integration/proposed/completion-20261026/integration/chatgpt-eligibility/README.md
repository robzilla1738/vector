# Current ChatGPT eligibility boundary

The October26 [official quickstart](https://developers.openai.com/siwc/quickstart) distinguishes open-source availability from limited commercial/private eligibility. Its [registration guide](https://developers.openai.com/siwc/token-sharing-open-source/sign-in) supplies the open-source dynamic-client flow. An unpublished Aux build is not proven eligible merely because that endpoint exists or the product has no payments.

The current Aux adapter already uses its own name, host ID, fresh state/nonce/PKCE and issued per-account registration. No borrowed client or owner login cache is proposed. These source properties do not establish vendor approval or a successful connection. Aux's eligible distribution category or private-client approval must be demonstrated before claiming public launch support; the owner has not authorized changing licensing/publication or submitting a partner request here.
