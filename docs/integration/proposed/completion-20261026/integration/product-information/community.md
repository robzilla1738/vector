# Community and feedback

Aux does not currently have a verified public community forum or a published support service-level commitment. This page must not imply that a forum, support mailbox or response-time guarantee exists.

Use the feedback dialog inside Aux to report a problem. Describe what you expected, what happened and which app version you used. Include only material you intend to submit. Remove provider credentials, sign-in codes, private page content and personal files from any report or screenshot. Review the dialog before sending.

If you need help getting started, read [Getting started](/docs). Development-preview capabilities that remain under verification are listed there. The owner still needs to choose and approve any public contact address, moderation policy and support commitments before they are published here.
