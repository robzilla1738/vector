# Getting started with Aux

Aux combines a browser, separate profiles and AI-assisted work. This development preview targets Apple Silicon Macs running macOS 27. Final package verification is still in progress; support for older macOS releases or Intel Macs is not established.

## Start with a fresh profile

Create a fresh Aux profile and keep work and personal browsing in separate profiles. Check the active profile before signing in to a site, opening a chat or selecting page context. This preview does not migrate another browser's profiles, passwords or AI credentials automatically.

## Connect your AI provider

Open Aux's provider settings, add your own provider credential through the secure input, then select an available model. Provider availability, permissions and charges follow your own provider account. Aux-hosted AI and Aux payments are disabled in the current launch configuration. A ChatGPT identity sign-in alone does not establish access to plan-based model usage; that integration remains subject to eligibility and consent.

Use a small test request before relying on a new connection. If a request fails or a capability is unavailable, keep the error visible and use feedback; a connected account or populated model list does not mean a request completed. Disconnect a disposable connection when finished.

## Choose context and permissions

Select the page, tab or file you intend to use. Review permission requests and the destination account. Browser actions and native features require their corresponding supported path and, where applicable, your OS permission. General shell/interactive-terminal capability is still awaiting its required platform entitlement and acceptance. Desktop observation requires explicit consent; it is not enabled simply by opening these pages.

Use your existing password manager through its browser extension. Aux does not provide a built-in password vault. Official extension, autofill and native companion compatibility are still being verified for this preview.

## Cloud features

Hosted sign-in, encrypted sync, private files, sharing and scheduled recovery require the configured Aux cloud service. Their final hosted activation and acceptance remain pending. Do not treat this development preview as a guaranteed backup service. Keep your own recoverable copies of important material.

For updates and feedback, see [Community and feedback](/community). Read the reviewed [Privacy information](/policy/privacy) and [Terms](/policy/terms) before using a public service; their current drafts require owner and legal approval.
