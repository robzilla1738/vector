# brand-media-a1

Eight extension assets showed Aside in their pixels, which text sweeps can't see. Each was retouched to read Aux, keeping dimensions, format, alpha and (for video) frame count, duration and codec. `manifest.json` lists every target with before and after hashes.

- Mini popup: "Ask Aside" → "Ask Aux" (Geist, bundled).
- CLI illustration: `~/Documents/aside/cli` and `/aside-browser` → `aux` (Geist Mono, bundled).
- Password-manager and payment-use illustrations: cursor label "Aside" → "Aux" (Inter).
- Channels cover: "@Aside", "Aside APP" and the Aside avatar → Aux text (Lato) and the Aux arch mark.
- Grant-permission dialog: "Aside wants to use…" → "Aux wants to use…" (Inter in place of Apple's system font) and the Aux mark on the badge.
- Both sign-in hero videos: the moving cursor label and the mock email domain, tracked per frame, including fades.

macOS Vision OCR over every output, including all 142 video frames, finds no "aside". Before/after contact sheets and the retouch scripts are in `out/live-inputs/scratch-brand-media/` (local only).
