# Retain the supplied command palette between invocations

Demonstrated defect: every Show loaded tabsearch.html again and immediately exposed the previous document. Input delivered there vanished on replacement; old DOM could temporarily retain previous command rows. Fully mounted Files was accepted, so no Files-route change is made.

Proposal: 20 counted anchors: existing native owner, private API event schema, event histogram enum/metadata, and one renderer resource. Native keeps the mounted document, rotates its existing invocation binding, and dispatches a typed private extension event restricted to the exact profile, Agent extension ID and live renderer process, carrying only its nonsecret document ID and shown boolean. The renderer synchronously resets view state and invalidates pending review/action continuations, then obtains the current context through the existing private API. Actions wait for that context. The same input DOM survives, and navigate-prefill/delayed select cannot overwrite newly typed edits. Hide invalidates async continuations and cancels the existing file review. Profile/browser retirement still destroys the existing owner. Initial document mount reads the current binding; no event is sent before that renderer has ever requested context.

No new public API, profile state, authority, CSS or UI structure. The existing private API gains onCommandInvocation; its receiver filters the exact palette document ID obtained through its own getCommandContext response, so same-process/same-profile windows cannot reset one another. The native generation remains authoritative and is never in event payloads. Renderer crash/remount creates a fresh document ID and listener; mount reads current native context. Initial pending events are matched only after document identity resolves, preserving any early text. ExecuteJavaScript was removed: Chromium correctly forbids it for this extension origin (RenderFrameHostImpl::CanExecuteJavaScript). No policy override or test injection. Existing native source baseline includes the grouped palette diagnostic projection.
