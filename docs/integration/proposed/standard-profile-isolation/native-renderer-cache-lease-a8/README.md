# A8 — acknowledged real renderer cache owner

This source-only slice implements the actual `CachedStorageArea` half of the live-cache boundary. It appends seven finite methods to the real `StorageAreaObserver` interface: begin, read-only discovery, validate, private stage/readback, final publish, original restore and exact release. The existing default UI, styles, ordinary storage methods and earlier Mojo ordinals are preserved.

Only the canonical Agent origin can acquire a new hold. An already loaded cache, bound actual pipes, no pending original mutation/physical callbacks, no prerender cache and a finite inventory of real source objects are required. Each source stamp comes from its genuine `LocalDOMWindow`/`LocalFrame` and current frame/document tokens. The opaque renderer token correlates that particular retained cache; it grants no native Profile, path, root, epoch, admission or target authority.

The actual canonical Agent storage callbacks are counted below their original normal completion closures, including Session recovery writes. A real reply retires work. A discarded callback leaves its count unresolved; no timeout or fabricated completion is used. The retained callback lifetime remains associated with its real cache owner.

During a hold, normal JavaScript reads keep the original view. Synchronous JavaScript set/remove/clear refuse with a temporary InvalidStateError before optimistic cache mutation and taint the hold. Lower-level void operations, observer events, connection resets and evictions retain their original arguments/closures for exact release; their attempts invalidate qualification. New source registrations and changed source/document inventory invalidate the hold. Deferred closures use weak ownership and cannot create a self-reference cycle. Destruction does not execute cleanup or report successful closure.

Stage accepts only the exact retained source and the finite reviewed legacy-to-Aux key mapping; values are unchanged. Duplicate/conflicting records and target quota failures refuse. UTF16 code-unit records preserve JavaScript strings without an extra UTF8 conversion. The target is a private complete cache map: stage does not change normal reads, write to the backend, invoke normal callbacks or dispatch StorageEvents. Readback observes that retained private target. Only a later explicit native publish changes the ordinary view, and the retained original permits original-owner restore. These acknowledged cache operations do not themselves establish backend or cross-store success.

The native backend/service cache cohort is the next integration slice. **No production native consumer calls these new observer methods yet, and A7 still refuses live cache owners.** Root must join actual native receiver/COW/namespace holds, physical backend source/CAS/sync/readback, the worker/editor producer holds and the durable cross-store intent before publish or activation. A native target-observer payload is data, never that authority.

The three existing native test observer classes receive explicit unsupported-interface compatibility so they remain concrete after the real interface grows. No new tests, success fixtures or runtime acceptance are introduced. One exact source/patch replay, reverse/hash/input preservation and whitespace check is recorded in `actual-source-check-a8.json`. Root owns actual Mojo generation, registration and compiler feedback; this lane has not compiled or executed the app or its helpers.
