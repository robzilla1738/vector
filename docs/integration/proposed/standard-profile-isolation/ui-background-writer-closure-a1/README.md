# Canonical worker writer closure — source implementation

This slice adds a real finite pause producer to the supplied Agent MV3 worker.
It preserves existing UI classes and ordinary original function bodies; it does
not add a new screen, permission or generic runtime API wrapper.

The exact adapter applies last, after the current identity and feature transforms,
to canonical desktop state version 2 only. This placement matters because the
existing Remix transform replaces the original prompt function. Earlier placement
would lose that producer owner. State version 1 remains unchanged. Unknown or
repeated inputs refuse rather than guessing a replacement.

`inputs.json` pins the supplied background file, actual full post-feature revision

`source-plan.json` includes full input/output hashes and exact counted anchors,
plus the three narrow shared composition edits requested from root. This lane
has not edited those shared owners or staged a successor package.

The actual changed boundaries include canonical local/session storage writers,
real native challenge callbacks under timeout, external password-extension
callbacks under timeout, daemon/bridge requests, command dispatch/cancellation,
context-menu and scripting callback queues, metadata/history/context/Remix jobs,
and the sidepanel opening preceding Remix dispatch. New work pauses before its
native write and remains pending until release. Native failures cannot disappear
because the original caller catches, disconnect clears a request map, or a timer
wins a race. Active tab-capture subscribers refuse capture.

The protocol and native binding requirements are in [PROTOCOL.md](PROTOCOL.md).
Root owns the actual EventRouter schema/API/ExtensionFunction and exact native
worker sender checks. Organization owns the native cohort controller and actual
