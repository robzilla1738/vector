# Genuine native child cohort lookup

This two-file successor extends the **current reverse-coverage descendant observer**, not its older a4 predecessor. It records each live kernel audit identity's actual first self-child root through native FORK/EXEC events. Fork descendants inherit that root; exec identity/version changes preserve it; exit removes the live identity. Reparenting cannot turn a known descendant into a human terminal. Existing global sequence/fence, reverse coverage, publication, original reaper and unknown-state rules are preserved.

`RetainActualClientCohort(kernelAuditTrailer)` is native-only and returns the unique existing published Ticket whose exact native birth window contains that actual root. It refuses absent/ambiguous identities, unready/closed/unknown streams, unresolved candidate publications, unmatched birth windows and settled cohorts. Absence remains unknown. No caller PID/parent claim, code signature, string task ID or JSON proof becomes membership.

The returned Ticket is a factual lifetime capability only. WorkerHost still must join that **same shared Ticket** to its retained ExecReservation/Owner and a genuine immutable native Profile/account task grant before inherited CLI admission. This slice adds no such grant, new C export, NAPI factory or standalone CLI readiness. It does not weaken the existing EndpointSecurity/native cold-start requirements or run any observer.

`source-plan.json` preserves two beforeimages and nine count-one anchors. `native.patch` and `static-check.json` record exact fresh-directory replay. Root owns paired SDK compilation and replacement of the current observer object in the actual48-Swift/14-native graph. No native build, process/owner-state read, product execution, signing or UI change occurred.
