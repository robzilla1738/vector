# Native selected-owner UI completion acknowledgment

Consumes only the opaque fact minted by the actual migration controller. The existing selected owner, private browser roots, process, current generation, fresh pulse and owned child are retained and checked before and after an actual authenticated read of the exact immutable terminal record. The move-only ACK is bound to that owner/generation/terminal fingerprint and revalidates its real owner on use. Failure or a lost read emits no ACK and never releases controller holds.

This accepts the completed UI transaction within the already admitted selected home. It does not select an installation, change stateIdentityVersion, publish cryptographic state, enable COLD or grant startup authority. Existing installation selection/checkpoint requirements remain separate. No Profile preferences, caller paths, renderer readiness booleans or new native export are introduced.

The interface target contains only the minimal fact header. Platform code does not depend on the full UI implementation target. Root must pair the actual controller implementations, generate and compile the native graph, then link a full successor before acceptance.
