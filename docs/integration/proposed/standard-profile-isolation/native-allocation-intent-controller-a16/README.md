# Allocation actions are distinct from physical target observations

The actual private Stage/intent consumer now accepts the append-only native
allocation facts. A genuinely absent Local map may retain an explicit finite
allocation action: the original map ID stays absent and the physical target map
and topology SHA stay empty until the real allocator result is observed. The
immutable intent binds the original absence, action digest and logical raw
target. No zero/future map ID or action-as-physical-digest is invented.

Unrequested allocation fields must remain absent. Requested allocation requires
the actual Local source absence, no original ID, a real action digest and exact
observed-ID presence semantics. This slice still makes no persistent target call.

The already consumed record transport now supports the protocol's fixed native
ordinal/kind/previous-receipt/original-intent fields. Existing kind1 ordinal0
behavior remains identical. Every receipt and fresh Load compares the exact
retained descriptor, and readback remains byte-for-byte. Future caller code must
mint only contiguous bounded native records; a journal record grants no actor,
write, drain or activation authority.

Fourteen counted anchors, exact input/output hashes and the append-only actual
wire dependency are recorded. Source replay is not native compiler/runtime
acceptance. UI and all qualification/activation/COLD behavior remain unchanged.
Root owns actual projection and compilation.
