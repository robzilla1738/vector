# Native DOM source holds and final renderer seal

This successor connects the existing real native controller to the actual A9
Local and Session backend/cache cohorts. It preserves the current UI and all
unqualified/activation barriers. It replaces the old loaded-area drain with
source holds; a completed queue alone is no longer the path to a sealed capture.

For each partition discovered from held actual Agent documents, the controller
creates distinct native request nonces and retains only partition ordinal,
control generation and exact service token. It reacquires the existing control
view at every boundary. It never retains a Mojo proxy across an asynchronous
operation, binds a new backend or accepts caller-selected namespaces/maps.

All actual editors flush before the worker, extension frontend and DOM gates
close. Every Local/Session Begin and Validate must acknowledge its own native
source/cache cohorts, exact source sync and private default target staging.
Only then does the controller call the existing read-only renderer Seal. Lost
Seal replies use the original lease's read-only observation. The final envelope
uses fixed numeric UTF16 units, preserving lone surrogates and absence. Raw
capture JSON remains opaque data.

The controller joins every reported cache source frame/document token to exactly
one retained actual native RFH, WeakDocumentPtr, extension document identity and
actual storage partition/key. Session namespace comes from the existing native
NavigationController. Every held document must have both Local and Session
coverage, and its final modern draft subset must equal the exact cache source
units. Unknown sources, missing coverage, owner changes, new writes or changed
map/topology facts refuse. Service snapshots and tokens are factual joins; no
renderer writer-closed Boolean grants native authority.

Final source validation includes the actual worker, same opaque frontend
readback, all DOM/cache holds and final renderer lease. It runs between bounded
capture transport frames and after exact durable capture readback. The capture
now retains freshly sealed envelopes plus native source map/topology/raw record
facts. It remains `captured-unqualified`, `qualified:false`,
`activationAuthorized:false`, `backendWriterClosure:false` and
`targetImportAvailable:false`. No Stage/Commit/Restore/Publish target call is
introduced in this milestone.

Cleanup first observes/releases the original DOM cohorts, then the original
frontend and finally productive renderer/worker restores. Lost Begin/Validate/
Release replies keep custody. Read observes the original request, same service
generation and exact token. Only a correlated successful release receipt or the
service's definitive no-lease failed-attempt record retires that attempt;
missing/not-found/changed-generation/destruction never means aborted. An
unacknowledged capture upload keeps all original source holds intact.

The one controller output has twenty-eight count-checked anchors against A10b.
`source-plan.json` pins exact inputs, output and real control-schema dependencies.
The focused source replay below checks the manifest and finite call graph; root
owns actual generated-Mojo/native compilation and application acceptance.

Remaining: privately derive/Stage sealed failed-memory targets; persist the
immutable cross-store intent before physical target attempts; real CAS/sync and
readback; exact live restore; durable restart recovery; separate cache publish
and final all-store qualification. This slice deliberately grants none of them.
No native execution/build, product lifecycle, signing, provider, owner-data or OS
permission action was performed in this lane.
