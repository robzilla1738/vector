# Local/Session native backend and cache-cohort controls

This is the six-file service/control integration for the real A9 AsyncDB/cache cohort. It owns only the two Local/Session control mojoms and the four existing LocalStorageImpl/SessionStorageImpl h/cc files. It changes no UI, native registry, storage paths, AsyncDB implementation or namespace implementation. The root integrator owns projection, Mojo generation, compilation and actual runtime verification.

Existing control method ordinals are preserved; the new operations append. The privileged existing controls now expose Begin, original-request Read, Validate, StageTargets, Commit, Restore, Publish and asynchronous Release. Targets contain only the captured map ordinal and reviewed selected key/value entries. Conversion rejects null rows, duplicate ordinals and duplicate raw keys before touching the backend. There are no caller roots, Profile selectors, map locators or restoration maps; the real backend validates exact coverage, native source/full-map CAS, allowed families/scope/schema/bounds and target-attempt freezing. Source restoration always uses its private native source custody.

Snapshots preserve backend topology/map digests, original persisted state, captured ordinal/ID and actual selected cache views/document stamps. The map ID and stamps remain factual data until the native controller joins them to genuine held browser documents. Numeric UTF16 arrays preserve exact JS code units. The organization owner confirmed these cache maps come only from the nine existing reviewed Aux families with their Local/Session scope; unrelated raw cache/backend maps stay private. No observer cache-control token is exported. `reply.ok` requires actual `snapshot.source_ready` and no native error, rather than merely possessing a lease.

The coarse A7 refusal for every loaded area/map/namespace is removed. The real AsyncDB registered-writer/cache preflight now owns that decision. A valid opaque backend lease remains held and discoverable when source preparation is refused/uncertain; `source_ready=false` never resets it. Each service retains an actual private generation, request and backend-issued token across asynchronous callbacks. A missing/stale service or impossible native null lease result fails closed. Read never retries Begin or creates a new backend. Each owner retains one finite successful release correlation (original request, exact service token and private generation), recorded only after actual asynchronous backend/cache/namespace cleanup. Read can then report `held:false,released:true` after a lost Release reply in that same generation; it carries no source-ready/writer-ready claim. A bounded process-local set of completed request tombstones prevents duplicate Begin from recreating a retired request after the detailed last-release receipt advances; once its 64-entry bound is reached, new Begin refuses rather than deleting replay history.

Session begins by preflighting all actual current namespace owners, then freezing their real receiver sets under the original native request before DB Begin. It records those private actual IDs without accepting them from callers. A definite pre-gate Begin refusal resumes that exact namespace set; uncertain cleanup keeps the original request held. Valid held leases retain namespace holds until real asynchronous release. There is no destructor-driven resume or synthetic success.

Release invokes the actual AsyncDB signature `ReleaseAuxUiMigrationLease(lease, AuxUiBeforeReopen, StatusCallback)`. Only the concrete native service builds this `DbStatus()` prerequisite from its weak owner, exact request/token and private generation. Local verifies that original native owner. Session preflights every retained namespace with `CanResume`, performs actual synchronous Resume calls while the backend ordinary-work gate is still closed, and reholds earlier resumed receivers in the same task if a later resume fails. A missing/stale/uncertain prerequisite returns IOError, keeps the opaque lease and prevents backend reopen. No Mojo/UI readiness Boolean or callback is accepted. Only actual successful asynchronous cleanup clears the service's lease/request and replies `released=true`; namespace error/rehold uncertainty remains discoverable on Read.

`source-plan.json` contains the six actual native beforeimages, fourteen exact single-match anchors and final source hashes. `native.patch` replayed and reversed in a disposable source-only mirror. `native-contract.json`/`dependency-pins.json` pin the actual paired organization-lane AsyncDB public API and Namespace freeze/resume/rehold declarations/implementation; the organization lane still owns coherent backend implementation and may add private orchestration declarations. Compose these services with that owner output, never with the historical A7 header alone. The source-level signature strings are recorded alongside full input hashes so later private owner changes require an explicit reviewed re-pin rather than a guessed ABI.

`static-check.json` is source evidence only. No actual native checkout mutation, Mojo generation, compiler/native API/product execution, owner data access or runtime readiness claim occurred. Root still needs the paired actual A9 owner implementation, native controller/document/journal integration from the other lanes, then one focused real Mojo/changed-owner compile and bounded authorized disposable behavior check. File-data sync/held cache observations are not directory durability, full-profile closure, activation or release authority.
