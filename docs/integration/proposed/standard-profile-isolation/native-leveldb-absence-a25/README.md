# Actual indexed Local LevelDB creation and exact absence rollback

LevelDB uses the actual captured storage key as its physical map identity. It has no SQLite-generated ID. For an empty originally absent native map, Stage now records explicit native target metadata: one actual native clock value for last access/modification and the exact target raw byte size. The timestamp remains fixed while the same staged creation is retained. Complete target map/topology hashes bind those exact planned values before any write. SQLite allocation behavior and original source metadata/digests stay unchanged.

The real LevelDB `UpdateMaps` owner writes key/value changes and both metadata records into its existing one batch. No empty usage record or unindexed raw map is created. Exact original-absence restoration uses its real `DeleteStorageKeysFromSession` owner, which deletes the actual captured metadata and raw key prefix in one batch. Existing complete source/target CAS, backend sync/readback, native/renderer cache custody, unknown-outcome retention and no-target-replay rules remain in force. Neither a caller backend flag nor an invented SQLite ID is introduced.

Four append-only target metadata fields are required for exact future reconstruction: `target_metadata_is_explicit` and optional typed `target_last_accessed`, `target_last_modified`, `target_total_size`. Wire/journal consumers must preserve nullable exact decimal microseconds since Windows epoch and unsigned bytes, as for the source metadata. The fields are valid only for actual LevelDB original-absence creation and are included in the immutable recovery descriptor. Source metadata remains factual original data; target fields describe the native staged plan, not a claim that it was written.

Two files / thirteen exact anchors over A22b. Actual LevelDB key encoding, data/metadata batch and exact deletion owners are hash/anchor pinned. Source replay/reverse/hash/whitespace only; no native compiler or product execution by this lane. Root owns compilation/integration, and productivity/navigation own the appended wire and journal fields. A clean original source must still be cancelable without inventing any never-written future target; the separate source-absence cancellation observation addresses that case and does not replay a write.
