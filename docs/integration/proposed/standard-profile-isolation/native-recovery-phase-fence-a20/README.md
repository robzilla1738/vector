# Preserve original recovery custody after a restoration attempt

Requalification uses the immutable fresh current source to reconstruct journal alternatives. After a dedicated original restoration starts, that fresh current source may legitimately cease to match. Calling initial requalification again could fail its baseline read and dequalify the still-retained recovery capsule. The successor refuses initial requalification once any actual recovery write has been attempted, before mutating receipts or the retained capsule. The caller must use dedicated ReadRecovery or the exact same original Restore retry, both of which inspect the separately retained journal original. Unknown outcomes stay held; no target write is replayed. One exact anchor over A19; source replay/reverse/whitespace only.
