# Actual native restart discovery and fresh-owner qualification

This successor connects the current controller to authenticated native journal
frames4/5/6 and the shared frame13 inventory/select codec, followed by actual
fixed-six frontend and Local/Session recovery leases. It is source-only and is
not a completed restart-recovery or runnable-app acceptance claim.

The controller reads one bounded native frame per UI task, validates capture and
record payload hashes, exact receipt chain/kind1/intent binding, current native
Profile binding and generation, and complete original raw records/metadata.
Incomplete tails remain explicit data. It never infers no-write from a missing
kind2, selects the latest filename, overwrites old files, or replays Commit.
Multiple unresolved originals without verified lineage refuse. Earlier journals
missing owner, metadata, partition or descriptor facts also refuse intact.

New source captures record the already-existing native PageIdentity and route;
new intents record actual StoragePartitionConfig. Restore correspondence uses
PageIdentity's real browser_tabrestore consumer and read-only FromWebContents,
without minting an identity. Historical partition ordinals are translated only
through an exact current native configuration match. The selected journal
channel is reserved across controllers while actual work/unknown custody stays
pending.

A verified unresolved original selects the supplied no-flush recovery capture,
then the actual MV3 worker hold, native frontend Requalify and independent
synchronized readback. Current DOM/cache actors are captured and sealed against
the actual RFH frame/document tokens before privileged same-token Requalify,
PrepareRecoveryCaches and ReadRecovery. Fresh source and recorded original
remain separate. Callback loss observes the same request/lease; no timer or
missing lease settles it. Generic cleanup and normal Commit cannot consume a
recovery lease.

This slice deliberately retains every hold at the pre-write boundary. A new
durable recovery-branch intent, original-source Restore/readback, renderer
adoption, the closed native/frontend/renderer handoff, verified branch-lineage
recovery, and final normal transaction still need the following controller
successor. Source-absence cancellation and owners without a proven persisted
page correspondence remain held. No installation/version marker, COLD admission,
qualification, activation, CSS, UI geometry, provider, credentials or app
lifecycle changes are included.

`source-plan.json` pins22 counted rules (23 replacements) and real dependencies. `evidence.json`
records replay and narrow source-boundary checks. Root owns actual compilation
and integration; none was run by this lane.
