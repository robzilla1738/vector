# Native Local allocation facts through the existing controls

This three-file append-only successor carries the paired A16 owner's actual allocation action/result through the shared Mojo snapshots and both Local/Session serializers. It composes over `e638d5cd1` plus definitive-result observation `799f7b523`, and pins the coherent native owner `d8cf5fb29` rather than reproducing its allocator implementation.

Each map appends `allocation_requested`, `allocation_action_sha256`, nullable `allocated_map_id` and `allocation_observed`. The reply appends the aggregate `allocation_action_sha256`. Existing `map_id` remains the original captured source identity. The new ID is copied only from the real backend observation; neither control accepts a future ID. Both physical target digest fields are forwarded unchanged, including an explicitly empty target map/topology digest while an allocation is requested but unresolved. An action digest is never substituted for a physical target digest.

The actual SQLite fact stays inside the existing AsyncDomStorageDatabase owner: it comes from its real Open result and passes `is_sqlite_` to the backend operation. No Mojo boolean, caller backend selector, arbitrary root or ID authority is introduced. The paired owner verifies unique real allocator metadata plus complete raw target readback before setting the observed ID. Session carries the same facts as supplied by its own native owner without pretending it performed a Local allocation.

After an uncertain write, the existing `ReadAuxUiPreferenceLease(original request)` still addresses exactly the retained native opaque lease/token/private generation. It runs the actual owner's readback rather than rerunning Begin or Commit. This serialization now exposes the discovered allocation observation from that read. Failure, pending/lost result, absent owner and a valid held lease with `source_ready=false` retain their prior semantics. Only the existing definite no-lease callback can yield `aborted`; no allocation field creates that conclusion or grants release/publication.

`source-plan.json` supplies exact predecessor source paths/hashes and six single-match anchors. `native.patch` replayed and reversed in a disposable source mirror. The unchanged two headers and Session control mojom remain the predecessor's outputs. Root owns the combined actual source projection, Mojo generation, changed-owner compilation and bounded native acceptance; this lane performed none of those operations and changed no UI or runtime state.

Factual original metadata for fresh-process read-only requalification will be a distinct successor after the native owner header is frozen. It must preserve timestamps/uint64 sizes as nullable decimal strings, not lossy JavaScript numeric fields. This A16 proposal makes no restart-recovery or runtime readiness claim.
