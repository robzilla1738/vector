# Native Owner settlement and clean-reopen caller

This proposal connects the actual retained WorkerHost Owner to the private Swift clean-reopen method. It applies after `runtime-publication` and alongside `restart-recovery` plus `runtime-coordination`; the latter supplies the actual `runtime_scope_pending` / `runtime_scope_unknown` fields. It is not an activated native input or a runtime claim.

The native query snapshots retained Worker and host records without holding Registry while acquiring Worker locks. It requires the exact retained Owner pointer, closed process-wide registration/factory admission, real image-census results, and every Aux native pending/unknown counter. Missing records, allocation failure, wrong process and unknown work never prove settlement. There is no NAPI/JS selector, PID probe, timeout or caller-supplied proof mask.

`RunAuxNativeNodeEnvironment` marks only its actual main Environment after `SpinEventLoop` returns on that native stack. That environment stays retained while the native loop completes clean acknowledgment; it is not claimed destroyed. Every other Worker environment must pass actual cleanup/detachment. The producer-shutdown overlay must physically settle JS background writers before requesting loop stop; this marker cannot repair untracked work.

Explicit host closure first closes all process registrations, then original factories/images/Worker writers. Only a successful native query permits the private Swift callback. Swift validates membership before dereferencing the retained pointer, then the versioned root admission performs actual authenticated browser receipt and durable paired CLEAN writes. Pending acknowledgment retains the Owner. The second native pass recomputes completion after acknowledgment rather than permanently merging the earlier pending observation. No host or Worker mutex crosses the Swift callback.

`make-overlay.py` pins three exact predecessor files and emits 18 count-one adaptations plus reviewable patches. `AuxStandardCleanSettlement.inc` is a new private implementation include. Count replay passes; C++/Swift compile and the full coupled successor build have not run. Runtime scope/descendant sources, authenticated peer transport and shutdown sequencing must be paired before integration. No accepted-app modification, product execution, signing, OS grant, owner state or UI change occurred.
