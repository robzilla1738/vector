Call `install(globals())` after the wrapper defines its validators and before `main()`. It replaces exactly `verify_research_projection`, `verify_link`, and `f.verify_guarded_native`. All other wrapper, feature and legacy assembler checks remain in place. The original browser guard is replayed in full; one count-checked insertion changes only the expected digest of the exact reviewed `launch_context_posix.cc` transition. It never changes a build receipt or frozen input map to make older verification pass. The package-review README's claim of no barrier intersection is historical and incorrect for this one file.

The operational review must pin `inputs.standardReview`, `inputs.standardNativeComposition`, `inputs.standardVerifier`, `inputs.standardCompileResult` (the actual a2 aggregate result), and `inputs.standardLinkResult` (the actual completed a3 link result), in addition to its existing references. Null, missing or stale references reject. The compile aggregate remains `passed:false`: its six dependency scans and six object commands succeeded, but its first link failed. Only the separately pinned a3 original-checker result can establish successful linking. Neither evidence grants runtime authority.
