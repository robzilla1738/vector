# Fresh-only Aux installation authority factory

`source/AuxFreshInstallationFactory.swift` implements the recovered factory branch independently of migration. It returns memory-only private representations, public encodings and a random 32-byte root. It performs no record reads, persistence, deletion, wrapping or implicit fallback. Nothing is wired into startup or the active native addon.

Admission explicitly requires four caller-asserted absent observations, a lowercase 64-hex scope and affirmative new-scope review. The type is deliberately called `CallerAssertedFreshAdmission`: it does not authenticate observations, prove actual absence, establish scope ownership, confer permission or replace all-writer custody. Present, invalid, inaccessible and partial observations fail before random generation or hardware calls. Real integration must obtain reviewed exact explicit-group reads and enforce native admission independently.

Pinned original `cmdInstallInit` selects software P256 when SecureEnclave is unavailable; otherwise macOS26+ selects enclave MLDSA65/MLKEM768 and older systems select enclave P256. Availability is an explicit input here so synthetic tests do not inspect hardware. Production integration must supply actual availability inside the authorized fresh boundary, never let a CLI choose downgrade flags. Factory failures propagate; no catch retries another scheme. Supplying a false capability on an unsupported OS refuses rather than downgrades.

Both P256 factories pass `compactRepresentable:true`. Software keys return raw private bytes; enclave keys return opaque data representations. P256 public keys are X9.63; PQ public keys are raw. Root creation uses CryptoKit `SymmetricKey(size:.bits256)` with extracted bytes. Enclave factories share the original access control: AfterFirstUnlockThisDeviceOnly, `.privateKeyUsage`, nil authentication context. There is no user-presence/biometric bit and no invented authentication prompt policy. ACL creation errors propagate. See `source-pins.json` for original instruction anchors.

The resulting material is usable by a separately reviewed Aux-v2 preparation/core adapter: import the representations with the existing scheme-specific recovered authority types, wrap the root using the Aux-v2 P256 or PQ algorithm, assemble strict Aux-v2 records, and perform durable four-row persistence only through the admission coordinator. This component does not claim that adapter or commit exists. Initialization reply preserves original scheme/public-field encodings; no legacy wrapping context is introduced here. Private representations/root are sensitive memory and must not be logged, serialized into a receipt or persisted by generic diagnostics.

Verification: `check.sh` compiles all hardware branches against the local CryptoKit/Security SDK and runs software-only synthetic authority checks. Tests cover each row position with present/unavailable/invalid observations, unreviewed admission, selection policy, software key import/public equality and signature verification. No hardware factory, Security API, Keychain, owner state, signing or persistence is executed. Hardware is compile-only, not operationally accepted.
