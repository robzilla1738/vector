# Supplied native section clipping container

New `aux::AuxSectionClipView` ports actual AsideSectionClipView4666440/metadata46666a0 used by the original expandable Bookmarks and Chats owners. It owns the real child View in a nonopaque layer with masks-to-bounds. The child keeps its full natural content height while the section animates the separately requested preferred height. This is not a replacement ScrollView or width-only collapse gate.

Original optional preferred height is field318/flag31c; an override returns width0 and nonnegative height, otherwise the actual child preferred size is cached. Layout independently uses optional content height320/flag324 or cached natural child preferred height, and sets child bounds(0,0,max(width,0),max(contentHeight,0)). Original caches328/330 and340/348 are invalidated by genuine child preferred-size/hierarchy changes. Source4667640 computes Chats natural row height separately from animated height and writes those two actual options. The new SetHeights method is a155 integration seam for the same two values, not a new animation algorithm.

Header `chrome/browser/ui/views/frame/aux_section_clip_view.h` exposes constructor(unique_ptr<View> child), contents() and SetHeights(optional<int> preferred,optional<int> content). Nullopt means use real child preferred size. The actual derived section owns SlideAnimation, expansion persistence and visibility; this class does not invent them or create rows. No body mount/removal is included. Held independent-body retirement must remain unapplied until the genuine replacement is complete.

Root must register both new h/cc files in the existing enabledMac view target with existing views/compositor dependencies. No existing native/GN source was changed. Source pins cover complete constructor, metadata, layout/preferred/invalidation and source Chats sizing caller. `python3 verify.py` verifies original bytes and independent two-new-file patch replay. No native compile, target execution, state/profile/credential/Keychain access, OS grant or network request occurred; actual visual acceptance is pending.
