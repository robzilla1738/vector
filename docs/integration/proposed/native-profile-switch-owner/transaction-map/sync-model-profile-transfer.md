# Per-model saved-group listener transfer

This is an actual Chromium155 platform adaptation of SavedTabGroupModelListener's registration boundary. It does not synthesize BrowserCreated/Closed or replace supplied group sync behavior. It retains the profile-owned TabGroupSyncDelegateDesktop, SavedTabGroupModelListener, LocalTabGroupListener instances, service associations, saved GUIDs, tab mappings and tab-owned WebContents listeners. Only the specific cohort's model subscriptions are suspended and rebound.

## API and required order

`SavedTabGroupModelListener::CanPrepareAuxProfileModelTransfer(span<BrowserWindowInterface* const>)` validates a cohort of actual current windows. The core must pass the positively owned visible/source-cache/target-cache windows, including every model whose collections will move, after actual cache creation. It checks unique genuine registered normal regular windows, model/profile identity, real profile factory service/listener registration, no active transfer/callback stack, no already-paused tracked group, and actual saved/local tab identity consistency matching stock ResumeTracking's requirements. Missing sync service is supported only when no actual listener exists for that profile.

`PrepareAuxProfileModelTransfer(windows)` rechecks and returns null without suspension when cold validation fails. A successful call returns an explicitly owned `AuxProfileModelTransfer`. It records weak actual windows/original profiles, pauses only tracked local groups contained in those models through the stock PauseTracking operation, then removes exactly those models' real listener subscriptions. It neither globally pauses all source-profile groups nor changes local-to-saved mappings.

The actual core then transfers the genuine collections and model/Browser identities using its existing ownership plan. Actual target/source groups keep the same tab handles and group IDs. All involved windows, loaded profiles and actual service owners must stay alive; the owner retains its already required profile keepalives/window lifecycle protection. This phase must be synchronous with no task pumping. WebContents listeners remain attached to their same-profile real tabs; remote sync/delegate callbacks must not be dispatched during this short suspension interval.

After all collections and real profile registrations settle, call `CanFinish(false)` then `Commit()`. The check validates real current Browser/profile/model identity, actual registry membership, every actual tab's BrowserContext, no foreign/existing observer registration, existing genuine profile listeners, and the exact retained group's tabs in one same-profile final cohort model. Commit reattaches each genuine model directly to the real listener belonging to its current profile. It then calls the unchanged stock ResumeTracking for the retained LocalTabGroupListeners, which independently checks real saved/local tab identity 1:1. No AddGroup, RemoveGroup, RemoveLocalTabGroupMapping, OnTabSelected, UpdateLocalTabId or remote action is invoked by the transfer methods.

If core source detach fails **before identity commits**, restore the actual source collections first, call `CanFinish(true)` and `Abort()`. This additionally requires every window's original profile. It restores real source observations and resumes the very same group listeners; it does not create an empty model or reconstruct fake saved data.

The transaction destructor CHECKs explicit completion. It does not fabricate an automatic success/rollback when windows or collections are unknown. If the surrounding core cannot guarantee window/service lifetime and no message loop throughout its existing synchronous commit interval, the provider must continue to refuse this capability rather than enabling a trigger on this proposal alone. Post-identity failure is not presented as a recoverable source rollback.

## Actual private delegate lookup

TabGroupSyncDelegateDesktop owns its listener privately and TabGroupSyncService exposes no direct desktop-listener getter. The proposal records each actual non-test SavedTabGroupModelListener in a Profile-to-WeakPtr registry at its real constructor and removes it in its destructor. Can/Prepare compare that actual listener's captured service with TabGroupSyncServiceFactory's real result. This is an authoritative owner lookup, not an alternate Profile identity algorithm, data store, fabricated service or public protocol. The actual observer maintains a narrow set of models it subscribed to, updated on genuine Browser creation and model destruction; base TabStripModelObserver still performs its normal destruction cleanup.

## Source evidence

* SavedTabGroupModelListener constructor observes the actual ProfileBrowserCollection; OnBrowserCreated calls model AddObserver. TabStripModelObserver's own model list/destructor manages generic cleanup, but does not transfer this profile provenance when a Browser intentionally moves collections without lifecycle events.
* OnTabGroupAdded calls the captured service AddGroup. OnTabGroupWillBeRemoved/TabGroupedStateChanged can disconnect real mappings; selection callbacks call the captured service OnTabSelected. Removing the actual cohort's top-level model observation prevents these migration artifacts without pretending browser closure.
* LocalTabGroupListener's PauseTracking explicitly supports a multi-step move with no net group change; ResumeTracking checks the genuine saved/local tab set. Its retained service/GUID/local ID are correct because real tabs move to the same-profile cache, not to a different profile's WebContents.
* The profile-wide ScopedLocalObservationPauser only pauses existing LocalTabGroupListeners. It does not suppress top-level creation/selection events and is deliberately not used here.
* New callback depths use destruction-only weak leave closures. No member AutoReset can unwind into a destroyed owner. No asynchronous tasks, fake sync events, fabricated API results, user-operation cancellation or global persistence flags are introduced.
