# Original region admission state owner

This proposal ports the actual retained-hover/collapse state graph into two new `aux::ProfilePreviewAdmission` sources. It is the prerequisite for the already delivered real preview input/capture adapters. It does not install a gesture, render a replacement header, or claim that a width-only current Chromium animation matches the supplied region.

The original fields are distinct: expanded hover `a08`, BrowserView retention request `a0a`, native edge-monitor retention request `a0b`, retained latch `a0c`, reversible collapse `SlideAnimation cd0`, and initial expansion transition `f78`. The real 100ms retained check is a separate RetainingOneShotTimer. Request release uses the SAME `940` timer as hover expansion, waits500ms, then checks the actual cursor predicate. Separate requests are never merged into a generic “expanded” bit. Clearing expanded-hover stops the retained check without clearing the retained latch; the real later idle decision or explicit clear owns that transition. ForceCollapse clears only the original a0a/latch fields, preserving the distinct edge producer state.

The constructor overrides SlideAnimation's default: SidePanelFlyoverAnimation disabled gives450ms/EASE_IN_OUT_EMPHASIZED; enabled gives350ms/ACCEL_30_DECEL_20_85. Reduced-motion policy gives zero duration. The genuine initial value is `!persistedCollapsed` (37e461c..4638). An expanded retained region becoming genuinely uncollapsed resets to1 and settles its real geometry immediately. Other collapse changes capture/hold real header geometry before actual reversible Show/Hide. The first and every subsequent genuine collapse frame clears f78 (46499b4); completion and cancellation both retire actual temporary-width/size/header-hold effects, while the delegate receives distinct completed/canceled outcomes.

`AdmitsProfilePreview(actualRegionWidth)` preserves the supplied exact guard: retained/hover expansion of a persisted collapsed region admits; idle noncollapsed admits; f78 uses actual width; otherwise floor(show)/ceil(hide) of actual slide value×target uncollapsed width is bounded by positive actual width and must reach151px. `VisuallyCollapsed()` preserves its separate five-state predicate. It is not the inverse of admission. Header/search visibility must use the actual ApplyLayout branch, not conflate these predicates.

## Integration contract and remaining port

The real region must own this state object and implement its mandatory Delegate against the SAME actual owners. The delegate shares the existing hover timer; it must not create a second release timer. The separate current velocity heuristic timer and click monitor are reset through `ResetExpandOnHoverTimers`. `RetentionAcquired` performs the original top-container resets. `HoverExpandedChanged` performs genuine pinned temporary width, timer/layout and metric effects. Collapse callbacks mark the actual tab/custom-scroll owners animating, hold actual header bounds before animation, apply actual layout each frame, and clear temporary widths/header hold at real settlement. Do not retain the independent BrowserAnimationController as a second collapse state oracle while binding admission to this SlideAnimation.

Original native edge-monitor event eligibility and the BrowserView request producer must forward their actual booleans; this proposal does not invent their semantic names or hook arbitrary focus/width events. `RetainedPointerInside` must port465020c/465034c with real widget/activity/root-screen/8px-side geometry. Original ApplyLayout464a8c0 is pinned in full for the coordinated header/region port. Public getters expose retained/hover/transition and actual slide state for that port. The actual mode gate still comes from the genuine vertical-tab controller. No unconditional eligibility callback is authorized.

Region/header mounting is deliberately disjoint from L4's current header/search proposal. GN must add these two sources to the existing enabled Mac Aux UI target; parent owns registration. Native compile and actual UI/gesture/capture observation remain outstanding. The proposal is source-only, with no shared native writes, target execution, owner state, network, OS grants or Keychain access.
