# Manual native close before logical archive

The actual Cmd+W trace reaches `TabStripModel::CloseTabs`, which delegates to `AuxOrganizationWindowController::HandleClose`. Its posted task archives an ordinary logical entry. `ArchiveEntry` captures only views that pass `Protected`; that predicate unconditionally rejects `NeedToFireBeforeUnloadOrUnloadEvents`. A durably archived record whose native view remains is deliberately displayed as “Recovery”.

The shipped positive predicate is proven statically: the Agent manifest injects `content/content.js` on all URLs at document_idle. The script's top-window startup unconditionally invokes Yf, which excludes extension origins but invokes Jf on ordinary loopback pages. Jf registers a document visibilitychange listener even before the capture preference resolves. Chromium's actual `NeedToFireBeforeUnloadOrUnloadEvents` returns true for a visible frame with that listener. The fixture itself has no unload handler; a passive extension listener is enough to trigger this broad native predicate. Exact shipped/source hashes are recorded in `source-check.json`.

This correction does not archive first and then bypass the listener. In the existing HandleClose path only, a current unarchived ordinary nonpinned/nonretained tab with that native predicate, no pending/blocked organization write, and no other protection continues the ORIGINAL native close. `TabStripModel` and `UnloadController` dispatch real beforeunload before any archive operation. Cancellation therefore leaves the durable logical entry usable and unchanged. Once accepted, the native CloseContents continuation re-enters with the unload bit cleared and the existing durable archive/close path runs.

`Protected` gains a default-true parameter solely to classify that preflight without treating the unload-listener bit as a separate veto. Every existing caller retains strict protection. Actor work, loading, split, media/capture, DevTools, downloads, runtime ownership, profile/document and storage guards stay intact. `CloseViewNow`, `ArchiveEntry` and automatic-archive bodies remain byte-identical. No new callback, beforeunload bypass, timeout, shared-close permission or storage-success flag is added.

Historical archived Recovery views are outside this new preflight (`!entry.archived`). They stay retained; this source patch does not delete or automatically settle the existing /palette-t Recovery row. Root can verify a fresh manual close while preserving that historical view.

`source-plan.json` contains four count-one anchors across the controller header/implementation. `native.patch` and the exact output files are supplied for root projection. `python3 check.py` passes replay, unchanged automated/close-body checks and the static listener proof. Root owns native compilation and the bounded actual close/cancel checks. No private native tree, app/UI, owner data, provider, signing or build action occurred here. Source checks are not actual runtime acceptance.
