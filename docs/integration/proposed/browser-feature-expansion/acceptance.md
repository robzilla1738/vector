# Focused final-app acceptance

This is a queued checklist, not performed evidence. Run only against the completed exact candidate in disposable state after the applicable native startup/authority gates and the owner's lifecycle restriction permit it. The accepted app stays intact. No owner profile, provider key, Keychain data, OS grant, product signature or hosted activation is implicit.

Record the exact app inventory/build/source-pair hashes, actual observed results and only the affected screenshots. Re-run a failed journey or a boundary changed by its fix; do not replay unrelated checks. Historical captures are a visual baseline, not acceptance of this build.

| Journey | One combined pass | Required observation |
|---|---|---|
| Frame and appearance | Dock/auto-hide/hover; URL controls in sidebar and top; right chat with both sidebars, bookmark bar and narrow window; minimal/full-URL; theme preview/cancel/reset | Current spacing, typography, glass and corners retained; no notch/overlap/phantom rail; focus/menu/drag keeps hover stable; real address/permissions remain trustworthy; default theme returns exactly |
| Organization and windows | Two disposable same-profile windows; nested/pinned folders, two Spaces/icons, wheel/swipe/+, shared add/reorder/close; independent selection/scroll; pin unload; remote navigation adoption; archive/Undo; cleanup selected-Space exclusions | One logical list, independent actual views; no URL deduplication, stolen window focus or protected-work loss; global pins retained across Spaces; durable acknowledged operations; cleanup skips all protected live views and never widens a deleted scope |
| Commands and layout | Cmd+T/Escape without commit; Cmd+L actual address; Cmd+K shared tab/Space/command; one shortcut import/swap/conflict; three mixed-axis panes, edge drag, resize/focus/unsplit and closed-pane restore | No blank tab until commit; selected logical view opens in originating window; stale context refuses; conflicts preserve prior shortcuts; real pages and histories survive pane changes; two-pane baseline remains unchanged |
| Utilities | Two synthetic downloads, rename collision/Undo and recent-file drag; explicitly chosen local fixture; viewport/area/full-page capture, save cancel/copy; Peek modifier/context action, quick window and exact-view promotion; local video PiP; active-pane DevTools | No arbitrary renderer path; actual move/receipt and collision refusal; page/profile-scoped capture and visible failure; no content upload merely from capture; no lost history or unsafe external navigation; real native utility action rather than optimistic success |
| Profile/lifecycle boundaries | Attempt switching during one real pending local file operation and one cancellable provider-free proposal; stale command/capture after navigation; scheduled restart/recovery only after explicit lifecycle permission | Real pending I/O blocks unsafe transfer; cancellation is not completion; no cross-profile cookies/extensions/context/file authority; committed state and independent window views recover without replaying agent work or permissions |

External password-manager extension/native-messaging trust, actual supported browser extension installation, real provider/eligible subscription execution, protected startup, complete writer drain, admitted-root recovery and atomic runtime publication remain separate real integration gates. A successful build, source fixture or screenshot of visible controls cannot close them. Mobile, payments, distribution and signing remain excluded from this desktop feature batch.

The final checklist report must state **observed**, **failed**, **not run**, or **blocked** for every journey, with the actual reason. Do not call the candidate ready while required journeys or underlying authority gates remain unaccepted.
