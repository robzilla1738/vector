# Native recursive split proposal

Source-only successor. Preserves the supplied two-pane path when `pane_tree` is absent. Eight genuine native panes maximum, mixed horizontal/vertical branches, stable slot identities and explicit collection-order mapping. Root owns shared registration and model/browser/session hooks. No WebContents recreation or URL-based identity.

Implemented in this slice: validated recursive component model, mixed layout/minimum sizing, branch resize/removal, versioned optional session payload. Invalid extensions refuse restoration rather than reinterpret existing state. Existing two-pane serialization remains byte-identical.

Verification: standalone tree source strict C++20 syntax passed; focused gtest source supplied but not executed. Native Views/model/drag integration and actual compile/runtime verification remain pending. This is not a finished user-facing split feature.

Native Views source now includes recursive layout over actual ContentsContainerView objects, dynamic divider handles and nested branch resize, N-pane focus/overlay handling, and native split tab rows. Two-pane layout calculations remain on the original branch. It requires root's `TabStripModel::UpdateSplitPaneTree(id, tree, intermediate)` and `BrowserView::PrepareSplitView` call before filling all slots. Source has not yet been compiled against the selected native build.

Shared integration still required before enabling N-pane commands: native tab admission with exact leaf-count validation; slot mapping update for reorder/removal; preserving remaining branches when a pane closes; metadata-first session restore; all-visible native contents/focus/profile-transfer iteration; actual drag/command entry points. The supplied binary split move helper rotates the first tab, so it must not be used for arbitrary N-pane reordering.

The accompanying `shared-hooks.patch` is for integrator review/composition only. It extends the real TabStripModel/TabStripCollection admission, moves and pane detachment; consumes topology before session restore notifications; and updates all-visible BrowserView focus/profile-transfer paths. Shared files remain owned by the root integrator.

Native command functions are `aux::JoinNativeSplit`, `CycleNativeSplitPane`, and `SetNativeSplitOrientation` in `aux_split_commands.{h,cc}` (add to native UI GN). They check actual same-profile/model membership and selected actor/runtime activity. Genuine native content-edge tab drag now extends an existing split; organization row center-drop uses exact logical IDs to open current-window views and invoke the same native operation. Outer row thirds retain organization reordering; Shift-drop requests stacking. Native split-pane close bypasses the organization archive interceptor and preserves the shared logical record as recoverable.

Remaining verification/integration gates: compile the full combined slice, integrate shortcut/command-registry entrypoints, inspect three/four-pane mixed layouts and drag/focus/resize in the actual disposable app. Partial session restoration with missing pane tabs conservatively restores those tabs individually instead of guessing a new leaf mapping. The history successor now restores full recursive splits and individual closed panes into a surviving split only if its exact saved tree minus that leaf still matches current topology. Intervening changes leave the restored tab ordinary. These paths remain native-compile/runtime verification pending. Nothing here establishes protected-startup custody or release readiness.

History successor: versioned tree codec is applied to both session and closed-tab history. Full N-pane restore no longer has binary count/leading-trailing assumptions. Removing/restoring one history member preserves remaining branches; malformed future history tree payloads refuse decode. BrowserLiveTabContext records each stable slot in existing tab extra_data, and exact-match undo never overwrites a changed surviving tree. The legacy vector restore default forwards two panes for existing platform implementations/mocks; actual desktop browser overrides N panes.
