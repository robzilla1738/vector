Other builds refuse the new function. The real retained account owner still validates immediately before and after the call. No caller path, account selector, launch permission or JavaScript binding is added.

The existing Exec export, rebuilt-PTY admission condition, general execution restrictions, sandbox exclusions and physical helper lifetime handling remain unchanged.
