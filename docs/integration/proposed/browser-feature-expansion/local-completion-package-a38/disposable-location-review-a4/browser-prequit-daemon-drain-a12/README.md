# Keep the actual browser authority alive through daemon shutdown

Actual supported A13 Quit fails when broker shutdown closes a real SQLite database under `withBrokerSync` after native parent authority has already been closed. The correct write guard refuses. The current browser pre-Profile shutdown hook already sends authenticated POST `/shutdown`; that endpoint starts the existing idempotent async producer/database shutdown and returns an immediate ACK. The supervisor treats that ACK as the point to close the Mach parent, racing the still-running protected database closure.

This three-file successor changes only ordinary native-mode teardown. A parameter-free native inspection wrapper observes/reaps the original selected child through the existing locked PID/birth/wait owner. It does not close the peer or grant/readmit protected work. `FinishNativeShutdown` keeps servicing the original authority and waits for actual original-child exit/reap before invoking the existing peer/FD/monitor cleanup. No missing-child/launch-failure/HTTP ACK/timeout is accepted as drain. The existing five-second deadline still returns failed while retaining unresolved ownership. Full-mode supervisor behavior remains byte-identical after the ordinary conditional is removed.

The hook remains `ChromeBrowserMainParts::PostMainMessageLoopRun` → `BrowserPlatform::Shutdown` → authenticated supervisor `/shutdown`. At that point Profiles, networking, UI task runner and published native roots still exist. No new HTTP or SIGTERM API, task architecture, post-root write exception or permission is introduced. All normal writer/account/root checks remain unchanged.

`check.py` verifies exact forward/reverse replay for three single-count anchors, unchanged full-mode supervisor bytes and shutdown trigger, no inspection-side peer close, actual original reap requirement and failure deadline. No native tree was modified and no executable/app/helper was built or run by this lane. Root owns projection/GN/compiler/build and must verify that actual daemon_supervisor compilation has `AUX_BROWSER_ONLY_NATIVE_STARTUP=1`; otherwise this conditional is deliberately dormant. Actual supported-launch Quit with browser/daemon/helper disappearance must be observed before calling shutdown fixed. Earlier failed runtime receipts remain failures.
