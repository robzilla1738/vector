# Private account directories for the actual fixed memory owner

Root observed the approved disposable control/task home directories as 0700, while their actual `u`, account 0/1 and task `memory` children were owned physical 0755 directories. The shipped account bootstrap creates them without an explicit private mode. The actual native registered account owner intentionally requires each held directory to be 0700, so the typed helper factory refused before creating a child.

This paired source-only change runs at the existing `initAccountDirectory` producer. It is limited to macOS with the same immutable ordinary flag and fixed native factory; full/supervised/absent-binding and other-platform initialization remains unchanged. It derives the account ID with the existing native-root account-locator check, then runs inside the real existing synchronous broker boundary.

Only these fixed paths are created/opened: native controlHome/u/id, native taskHome/u/id, and native taskHome/u/id/memory. Roots must already be private 0700. Each child is opened as a directory with O_NOFOLLOW, checked against its exact named inode/canonical path and actual uid, and checked again after each step. Unknown modes refuse; only owned 0700/0755 directories qualify. Existing 0755 directories are tightened via their exact held FD, fsynced and read back as 0700. New children are created with explicit 0700. All retained FDs close on success or error. No enumeration, file contents, credential reset, native guard relaxation, ACL removal, global umask, arbitrary root or generic execution is introduced. The original bootstrap then continues unchanged.

`source-plan.json` pins the exact A45-paired inputs and one counted account-initializer anchor per leaf. Generated paired files live in a fresh `/private/tmp` directory. Forward/reverse exact replay and both actual output syntax checks passed; the product source was not evaluated. Root owns integration, signing and actual runtime acceptance. No app/UI/owner files, native checkout, permissions or credentials were changed by this lane.
