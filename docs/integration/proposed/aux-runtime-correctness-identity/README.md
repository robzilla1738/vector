## Recovery authority limitation

`findPortOwner()` obtains `ps -o comm= -p <pid>`, not argv. The replacement accepts only the Aux executable basename with an optional absolute whitespace-free path, explicitly allowing its actual `Aux Daemon.app` bundle segment; it rejects `faux-daemon` and argument-bearing strings. False negatives for other paths containing spaces are intentional. This is executable-name recognition only. The original recovery body has an isolated-port/PID/name check, **not authenticated installation or same-home authority**. Automatic recovery still needs an independently reviewed same-home/ownership fence before activation. Keep this helper inactive in the quarantined successor until that fence exists; no running process was queried or signalled.
