`CollapseTransitionStarted` intentionally holds expanded header geometry and pinned-grid layout width. The supplied-style collapse admission continues laying out the full controls while frame geometry reduces the enclosing region's width. Pinned tile EntryViews explicitly own compositor layers (`vertical_pinned_tab_entries_view.cc:171`). The region itself owns a nonopaque layer (`vertical_tab_strip_region_view.cc:135`) but never masks its descendants. Paint clipping of ordinary Views does not clip these independent descendant compositor layers. The existing frame visibility guard only hides the subtree once its bounds become empty, so it does not address transition frames with positive shrinking width.

One counted anchor sets the existing region layer's bounds mask from the same current admission state that controls animated presentation: collapse/expand animating and not retained. Progress, settlement and cancellation all call ApplyRetainedLayout; the existing admission resets its transition latch before settlement/cancellation. The mask is removed when motion ends and throughout retained hover, preserving the shadow child that must paint beyond the floating surface. No new timer, stale state latch or persistent clip is introduced. Header/pinned layout remains held as intended; only overflow painting is constrained to its owner's current bounds.
