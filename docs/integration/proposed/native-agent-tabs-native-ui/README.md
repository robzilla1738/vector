## Platform adaptations and remaining fidelity gaps

Chromium155 API adaptation uses current TabInterface handles, ScopedObservation/FocusChangeListener and its native hover-card controller. `SetNotifyEnterExitOnChild(true)` preserves geometry-based hover over child controls; native focus observation also retains the close control while focus is inside it. The supplied original stores byte1cb true and checks hover/focused-descendant state in the recovered row enter/exit/focus methods; no account or ownership permissions are derived from hover.

Original private semantic color IDs 215/221/222/225/226 and custom rounded hover/pressed painting have not yet been mapped into the155 palette. This proposal uses actual platform label/icon/separator/bubble defaults rather than pretending the old numeric IDs mean the same colors. Consequently color and hover/background paint fidelity remain incomplete. Exact intrinsic width/wrapping under long titles, native child-focus presentation and live marked-group lifecycle still need actual compilation/UI observation. No full parity or runtime acceptance claim is made. Original separate secure AI-tabs creation, automatic MultiContentsView takeover, and disk-session restoration are outside this UI slice. Whole-group profile-cache transfer already retains the exact group/features object naturally; see the committed `native-agent-group-transfer` proof, not a title-based restoration shim.
