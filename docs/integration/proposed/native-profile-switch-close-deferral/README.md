# Preserve normal close requests across a synchronous profile transfer

Actual155 BrowserView::OnWindowCloseRequested hides the frame and permanently suppresses layout before invoking UnloadController::OnWindowClosing. The earlier Aux empty-suppression guard makes that unload callback return during transfer; with an empty model, the view still returns kCanClose. Actual BrowserWidget::OnNativeWidgetDestroyed then synchronously destroys the Browser. A genuine ordinary close callback can therefore hide/tear down the physical owner midway through a transfer, or be lost behind the unload guard.

This necessary platform integration adds a narrow actual Browser close-deferral query at the very start of the client close request, before beforeunload/hide/layout teardown. While and only while the actual synchronous profile mutation is active, it retains one genuine close request for that physical window and returns kCannotClose. Existing request behavior outside that interval is unchanged. After actual commit/source rollback settlement, weak mutation release posts the real BrowserWindow::Close; the normal unload/user/policy checks then run. It never claims a requested close already completed. Cache/visible windows use their own actual weak Browser identity; queued suppression clears precede the retry. Multiple nested close requests for the same physical window coalesce to the same actual close action.

The three mutation guards now release through actual weak Browser callbacks rather than member AutoReset pointers that could unwind into a destroyed Browser. This does not claim arbitrary forced CloseNow/native destruction or all provider callbacks are safe: the complete core/provider/cohort weak retirement audit remains outstanding before activation. No synthetic Commit/Abort is introduced and no user operation is silently dropped. No UI trigger is enabled.

Five exact source input/output hashes and independent patch replay pass. Native compilation and actual close/profile behavior are pending. No signing, owner profile, OS grant or runtime action occurred.
