Three exact unchanged current v83/v84 inputs. BrowserLiveTabContext stores a Profile reference used by restored-tab/group creation and its destructor's TabRestoreService cleanup. The same physical window, model and SessionID survive the supplied profile transaction, so its live context must follow the genuine target at the empty-model commit.

Rebind validates the same actual userdata, model and SessionID. It asks only an existing old-profile TabRestoreService to retire this context through BrowserClosed, then replaces the profile source. Actual TabRestoreServiceHelper::BrowserClosed only erases the context from closing_contexts_; it neither manufactures a closed-window history entry nor closes a native window. No missing service is created by cleanup. The existing target-profile restore factories and actual model are used afterward. There is no Prepare effect; a pre-identity abort leaves this context unchanged and must not call the empty-model rebind after restoring populated tabs.

Its per-tab path also verifies actual WebContents BrowserContext before resolving the real current window. Stale or foreign references return unavailable, rather than acting on target profile data. Existing non-Aux/Android behavior and the ordinary global lookup remain unchanged.
