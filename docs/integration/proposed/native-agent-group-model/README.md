This is a source/model prerequisite for the original native agent-tabs control. It implements the actual recovered marker producer, rather than inventing a parallel ownership ledger or treating every similarly titled group as agent-owned. The existing guarded Aux bubble/actions remain unchanged in this slice.

## Audio and membership

Actual helper `041e331c` marks an unmuted member using SetTabAudioMuted(true, reason5, emptyextensionId), and leaves already-muted content and its reason intact. On removal it changes only currently muted contents whose reason is5. It restores a blocked normal page's real SOUND content setting with content-setting reason3; otherwise it unmutes using the dedicated reason. Empty/chrome URLs skip the content-setting lookup. The155 enum appends kAgentGroup at5 without changing existing values.

Original membership path `041e34f8` reads old/new actual group feature flags and changes audio only if those differ. The port captures both flags before removing an emptied source group can destroy it, then applies audio after real membership/model observer notifications. Joining an already marked group therefore applies its owned mute; leaving it restores only that owned mute. Moving between two marked groups retains it. No user, extension or site mute is blanket-cleared.

## Chromium155 adaptation and integration

Eight files are pinned. The sole new public header is `content/public/browser/devtools_authenticated_session.h`; root must add that header to content/public/browser/BUILD.gn's sources. Its free bool helper is implemented in the existing devtools_agent_host_impl.cc. It resolves the actual private host registry by GetId, requires pointer equality, and reads actual live sessions' clients. A narrow friend in the private Impl header permits that read; no public client list, duplicated registry, core DevToolsAgentHost virtual/header edit, trust heuristic or cached authentication is added. Default/unregistered/fake hosts returnfalse. The query is UI-thread-only.

155 distinguishes tab and page targets, so the member scan checks an existing tab host, then an existing page host guarded by HasFor before GetOrCreateFor. It does not create a debugging target just to query eligibility. The source's browser fallback is preserved. The separately delivered secure-page proposal must compose first for full original page-client parity.

Aux-specific producer/audio effects are gated by ENABLE_AUX_BROWSER. New marker fields defaultfalse. The exact original unused+20 visual string field is not synthesized: current155 visual data has no corresponding consumer, and it is not required for this marker/count prerequisite. Existing native workspace restore producer `045f4bf8` and the source's secure AI-tabs metadata command `046b4200` are separate call sites not registered by this patch. New tabs grouped by the supplied1852 bridge use the implemented actual visual-update path. Marker persistence/other original producers remain explicit future integration work.

This does not yet replace the guarded daemon-backed bubble with native group rows/count/visibility, add original hover/context effects, or establish complete agent-tabs fidelity. Apply only against manifest pins. Static verify.py checks original bytes, exact replay, live-client authority, collapse/marker preservation and mute/membership ordering. No native build, target attachment, network request, audio/OS operation, owner state read or runtime acceptance occurred. Root owns application and focused native compilation after its current full build.
