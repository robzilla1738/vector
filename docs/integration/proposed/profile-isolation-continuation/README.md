  32 session consumers. Task attachments, artifacts, tools and caches use the
  native task-home projection; private messages, settings and credentials stay
  in control storage. Arbitrary legacy roots are rejected. Six focused fixtures
  and transformed-module syntax passed. Locators are not filesystem authority.

  validates all six final directory slots against retained native browser roots.
  Outside-root cache overrides are refused without rewriting preferences or
  widening a live child's permitted paths. Four actual translation units and
  one disposable filesystem fixture passed. The shared Chromium tree is not
  modified and the gate is not activated.
* `broker-writes/`: actual retained native Owner admission, readonly native
  control/task-root capture, synchronous JSON/SQLite guards, route admission,
  shutdown admission closure and explicit uncertainty for detached producers.
  The changed host object and paired 47-source Swift graph passed; five focused
  fixture groups passed. The public host class layout remains unchanged.

  module, v6 policy decoder and sequential task/broker source composition. The
  first cold-entry refusal remains byte-identical. The current route requires
  the exact new PTY binary; older policy versions remain historical decoders.
* `brotli/`: official source1.2.1, pinned by SHA-256, compiled separately with
  the original35 Node translation units for arm64/macOS13.5. All130 existing
  global symbols remain. The historical archive and source tree are unchanged.

## Still required before activation

1. Implement the genuine browser-root authorization request and retained lease
   before `JsonPrefStore::ReadPrefs`. Current root capture proves provenance,
   not permission to read a profile. Selected-home installation readiness is
   not a browser-profile authorization grant.
2. Complete asynchronous filesystem/background/logging writer custody,
   cancellation and SQLite cleanup/checkpoint lifetime. A synchronous callback,
   resolved Promise or returned HTTP response is not universal proof of drain.
3. Provide atomic beneath-root filesystem access where required. The cache gate
   resolves existing symlinks but cannot close a later descendant replacement
   race; its six directory slots do not cover every file-valued network input
   or every browser writer.
4. Integrate the native Chromium patches into a coherent candidate graph and
   full browser link. Pair exact daemon, PTY, source, policy and trusted helper
   provenance; keep old policy/source associations unchanged.
5. Perform bounded disposable actual-candidate startup, switching, cache-refusal
   and shutdown checks after those implementation gates exist. No successful
   real-app or UI-comparison result is claimed by this source/native batch.

Existing profile migration is not silently enabled. Owner credentials and old
state are not adopted, rewritten or deleted. Signing and release remain separate.
