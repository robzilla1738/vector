# Native-v2 stage decoder and four-target boundary

Inactive source, accepting only the privately constructed genuine `NativeFreshStagedContext`. Production has no caller-payload/context constructor, selector or absence flags. It revalidates actual authenticated policy, retained-home/reservation lineage and current durable initial record through that context, then recaptures the exact fifth secure row. No v1 review record is reinterpreted.

The private decoder enforces the exact native-v2 stage field/nested schema, transaction/reservation/policy/scope/candidate, ordered selectors, public descriptor and all four raw-payload hashes. Base64 must be canonical; metadata has exactly scheme/key_storage. Actual recovered signing/KEM imports enforce the expected public keys; a native-v2 challenge verifies signing continuity, and the actual Aux-v2 envelope/core opens a 32-byte root. Hardware branches are compile-only. No raw private payload/root is persisted or logged.

`AuxNativeFreshTargetBoundary(context:)` retains only its genuine context and validated sensitive payloads in memory. `captureTargets()` returns actual exact-group DP captures under the four sealed selectors, with stage/host/home revalidation before and after. Present, absent, unavailable and invalid are distinct. `addTarget(_ intent:AuxNativeFreshTargetWriteIntent)` validates exact initial-journal/transaction/row lineage, consumes the native private-init CURRENT durable-intent ticket, revalidates stage and target absence, then uses **only its own decoded payload and selector** in `SecItemAdd`. There is no update/delete/fallback. The actual target coordinator owns durable intent/status/unknown-outcome recovery; a loaded intent cannot mint a new ticket. A post-Add error remains uncertain, never permission to replay.

`validateStageAndMakeCommandCore()` requires all four actual target bytes to match the decoded stage and raw hashes, independently imports/validates that actual target authority, and only then returns a command core. A valid stage alone does not produce a terminal installed context.

Read queries preserve generic-password, explicit group, DP true, return-data, match-one and authentication-UI-fail. Adds preserve exact identities, DP, AfterFirstUnlockThisDeviceOnly and create-only semantics. The deprecated prompt-suppression constant is retained deliberately. Production would perform protected operations; none is authorized or executed by this proposal. Compile-conditional captured effects are absent from production builds.
