# Real bookmark IPC profile boundary

Two exact untouched v71 source inputs. The current per-window BookmarksServiceFeature owns a merged bookmark service observation, a concrete Mojo bookmark service with active receivers, and queued receivers. A raw profile or model swap alone would leave live old-profile IPC attached to the newly selected window.

Prepare invokes the actual existing ShutdownService before identity: it removes old observation, destroys the concrete service/active receiver ownership and drops all pending receivers. During this synchronous gap Accept has no service and closes requests normally. Rebind validates this same window owns the feature and derives the actual merged service through that window's current regular profile factory. It observes the real target and uses existing loaded/deferred initialization; genuine service absence closes receivers rather than returning fabricated empty bookmarks. No old receiver is transferred to target and no bookmark/user data is copied.

The same feature/userdata identity survives. Abort rebinds the actual restored source window. Root's Features plan must prepare before tab/identity effects and rebind only after the authoritative current profile is coherent. The classic BookmarksUI binder resolves its current window dynamically from the actual TabInterface, so a transferred source tab reconnects to its own cache window's source feature. The other WebUIBrowserUI binder belongs to the separately unsupported WebUI window graph; this patch does not declare that graph compatible or replace its UI.

This is a required Chromium 155 platform adaptation for the supplied in-place algorithm, not a claim of an identically named shipped method. Exact two-file disposable replay passes every output hash. No shared source writes/build, live Mojo/browser execution, bookmark/owner state, network or OS access. Compile actual BookmarksServiceFeature and expose its public header buildflags dependency as needed. A disposable connected-client migration check remains required before claiming runtime IPC isolation or full provider acceptance.
