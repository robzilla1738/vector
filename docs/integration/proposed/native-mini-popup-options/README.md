# Supplied mini-popup option window handoff

Proposal only: no shared source writes, native build, launch, signing, profile, Keychain or OS preference operation. Targets the actual applied **v32** `aux_mini_popup_api.cc` and its local `BUILD.gn`; exact input/output hashes are in `manifest.json`. The only new dependency is `//net`, for Chromium's existing query parser. No root registration/schema/GN or supplied Agent/Vault files change. The staged profile-switch owner work is outside this proposal; compose its `switchProfile` hunk separately after this baseline.

The supplied1852 composer opens `minipopup-options.html` using `window.open`, preserving its current query and adding left/top/width/height/focus. It portals the live model menu into **that returned document**, invokes `setOptionWindowSize` from the child, and closes that child on dismiss. The existing Aux adapter had no `AddNewContents` handler and independently loaded a second option document from `ResizeOptions`, which cannot contain the React portal. It also rejected the real compact92px height with an invented120px minimum.

This patch retains the actual newly created WebContents in the native child WebView. It admits only the main popup's same-extension `NEW_POPUP` with positive query dimensions, uses the supplied query position, and honors `focus=false`. Other popup requests are blocked. The original `window.open` relationship, child document, query state and JavaScript close lifecycle stay intact. `setOptionWindowSize` now resizes only that exact child, preserving its bottom anchor and fitting the display work area. It cannot create a replacement document or resize another extension page. Main hide/state/size calls likewise require the actual main popup WebContents. The shared existing profile switch branch is untouched.

Native constructor/state constants restore440×92 initially and440×92/148/534 for compact/attachments/expanded. Source1852 browser-binding independently fixes its dynamic size requests to440px. Both size APIs accept the original strictly positive integer contract; no artificial minimum/maximum remains. Existing main popup positioning/material and the optional child bounds animation are not changed by this slice.
