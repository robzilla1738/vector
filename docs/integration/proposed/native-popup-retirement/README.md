# Supplied popup retirement and compact state

One-file follow-up after `native-popup-picker-lifecycle`, CC baseline `1b49218ed290f8db7fc9efaeaaa99d703a55fb86f32de9eb6b0f67b81f2a4588`. `manifest.json` and `native.patch` pin the exact delta. No headers, schema, GN, startup or shared native files are changed here.

Original enabled-pref observer04599728, on disable, removes the coordinator from the global manager and destroys it through04595260, then unregisters/clears its accelerator registration. Aux previously unregistered and hid the retained popup. The proposal destroys the actual main/options tree on successful disable, cancels any dismissal task queued by that hide, clears the actual accelerator value and resets the next requested size to440x92. The registration error/rollback policy is unchanged; this does not pretend a failed disable succeeded.

Original coordinator creation04594b00 initializes composer state+0xb0 to0. Original main creation0459577c initializes its desired size to `0x5c000001b8` (440x92), and original SetState's state0 selects compact92. An actual profile retirement creates a fresh coordinator in that implementation. The global Aux host now resets its size to that compact value **after retiring the old windows and before installing the target profile**. It no longer carries the former profile's expanded/custom requested size into a new popup.

Ordinary Hide/reopen and the same-Profile early return remain byte-identical. They retain their actual page/draft/requested size and are deliberately distinct from disabling or changing profiles. Material, animation, source-scoped picker lifetime, locked routes, focus restoration and the actual security fetch remain unchanged. This resets native presentation state only; it does not set any account/Vault/onboarding state.

## Remaining bounded public-API/lifecycle audit

The supplied IDL has ten methods and no public event surface. Do not add invented MiniPopup events. Current response shapes are bool for getEnabled, string for getShortcut, no arguments for setters/hide/switchProfile, optional path for pickDirectory. The picker follow-up restored that last optional result. Original state values are compact, compact-with-attachments and expanded; original size arguments are strictly positive integers. Those are already enforced by the actual host; this slice adds no size minimum, cap or new state.
