## Completion standard

Integrate disjoint source changes into one serialized native build, retain the existing helper bytes, and verify the exact package before launch. Use disposable state. Perform one focused actual-app journey for each changed boundary and compare actual UI with saved Aside references. Record successful observations and limitations separately in `docs/STATUS.md`; never mark backend, credentials, OS grants or physical-input prerequisites complete from a source audit.
