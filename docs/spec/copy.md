## Copy ownership and dynamic values

Dynamic task titles, user-authored instructions, filenames, domain names, provider/model names, extension names and imported field names come from their actual records; they are not copied product prose. Browser-source/provider proper names may identify compatible third-party products. Runtime errors should be mapped to the original Aux error phrases above plus a sanitized actionable detail, without exposing raw secrets. Count/date/duration formatting is locale-aware; pluralize records rather than hard-coding singular labels. New controls introduced by later evidence must add catalog entries in the implementing slice instead of copying strings from reference chunks.
