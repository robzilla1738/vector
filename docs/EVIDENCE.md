# Aux evidence ledger

Updated September 26, 2026. This ledger records what the current code or a recorded run proves. Requirements and acceptance criteria live in [ROADMAP.md](ROADMAP.md). Historical detail is retained under [archive/](archive/README.md); archived completion claims do not transfer to the new Chromium host.

## Labels

- **[Verified]** Observed in current code or a recorded run, with a linked artifact or exact command and revision.
- **[Partial]** Demonstrated only in named conditions; remaining conditions are explicit.
- **[Promising]** Strong reference evidence, not yet tried in Aux.
- **[Assumption]** Untested; a named spike must prove it before dependent work.

A passing fixture, mock UI, or Electron run is never evidence for a native Chromium journey. Record failures as failures. For any speed claim, add raw data and a row to [BENCHMARKS.md](BENCHMARKS.md).

A named retry policy replaces ad-hoc retries: only `target_detached` (a pre-dispatch resolution code) earns one retry after an `interactive` settle — `ref_stale`, `conflict`, and any post-dispatch failure are never replayed. Un-armed dialogs route through `decide()`: `DriverPageEvents.decideDialog` resolves via the page's active claim's run — `deny` dismisses, `ask` parks the run's typed suspension and leaves the dialog open, `allow` keeps default handling; an armed `dialog` step's accept still wins. Non-native downloads save into the configured session `downloadsDir` (`saveDownload` sanitizes the suggested basename and suffixes collisions), so `expectDownload` waiters resolve a durable path instead of a per-context temp artifact. Page claims are durable: `page_claims` records `owned`/`borrowed` claims on every `PageOwnership` acquire, releases on final release and per handoff (outgoing claim closes before the waiter's opens), re-claims an active `(run,page)` row instead of duplicating, and `releaseOrphans(liveRunIds)` clears claims whose runs did not survive restart — mirroring suspension recovery. `pnpm typecheck` (both steps), `pnpm lint` (0 errors), `pnpm format:check`, and the canonical `npm test` (242 files / 1,166 tests) pass, including new `s4-actuation` (14 tests: claims store, ownership ledger handoff, retry policy, before-state, readiness policies, scope contract, downloads dir, delta gate) and three jsdom observe-filter tests. `pnpm bench:observation` ran: aux observer found all fixtures at equal-or-better coverage than accessibilityHtml (records 2,806 chars 2/2 facts, detail 850 2/2, form 1,562 2/2 vs its 0–1/2); the records snapshot is ~2.74 KiB, inside the ≤2.8 KB budget.
