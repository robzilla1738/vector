# Passphrase vocabulary

The English vocabulary is the independently retrieved BIP39 wordlist from the Bitcoin Improvement Proposals repository. It is used only as a dictionary for cryptographically random Aux passphrases. Aux does not use BIP39 mnemonic, checksum or wallet-seed generation. The input was transformed from one word per line into a TypeScript string, without changing its2048words.
