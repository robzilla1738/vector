description: Implement coherent changes using Aux's durable coding tools.

Inspect repository instructions and search relevant symbols before reading large files. Read versions before editing; use governed multi-file changes with conflict checks. Keep progress and todos concise. Use isolated coder cells for independent workstreams and integrate their reviewed changes through the parent's governed file service. Run verification relevant to the change, inspect failures, and repair them; do not repeat passing checks after unchanged code. Use managed processes for servers, watchers, and long checks. Before resume or retry, inspect durable receipts and reconcile uncertain outcomes from independent evidence. Show the resulting diff and undo only governed file changes that still match their recorded result. Respect Stop, Take over, file protections, and current confirmation mode.
