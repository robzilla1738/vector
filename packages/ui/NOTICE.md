# Independently acquired UI dependencies

Aux's geometric mark is original. Interface glyphs use Lucide (ISC), acquired from the public `lucide-react` npm package. Geist, Geist Mono and DM Sans use the SIL Open Font License, acquired from the public `@fontsource` npm packages. License notices are retained in `licenses/`. No reference application assets or fonts are used.

The extension also uses React (MIT), TanStack Router (MIT), Tiptap (MIT), react-markdown (MIT), remark-gfm (MIT) and Vite (MIT) as declared npm dependencies. Package distributions retain their upstream notices.
